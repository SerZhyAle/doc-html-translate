محوّل المستندات لنظام Windows · GUI · CLI · إضافة Chromium

حوّل أي كتاب أو مستند أو قصة مصورة إلى صفحة ويب محلية

اقرأها وابحث فيها وترجمها بترجمة الصفحة المدمجة في المتصفح - مجانًا ودون مفاتيح.

لكل من يقرأ الكتب والمستندات بلغة أخرى: تتحول ملفات EPUB وPDF وMOBI وFB2 وRTF وTXT وMarkdown وHTML والقصص المصورة والصور إلى HTML محلي مع فهرس وتنقّل. ويتوفر التعرف الضوئي على الحروف (OCR) للصور.

EPUB / PDF / FB2 / CBZ / ..→local index.html→Chrome / Edge→قراءة وترجمة

التثبيت والتشغيل

يُثبَّت تطبيق سطح المكتب (نافذة + سطر أوامر) وإضافة المتصفح كلٌّ على حدة. جميع الخيارات مجانية.

Microsoft Store GitHub Releases مثبّت setup.exe Chrome Web Store Edge Add-ons
  1. ثبّت التطبيق من Microsoft Store أو عبر winget أو بالمثبّت، أو نزّل أرشيف zip المحمول من GitHub Releases.
  2. افتح ملفًا مدعومًا في نافذة التطبيق أو بالأمر أدناه.
  3. ينشئ التطبيق ملف HTML ويفتحه في المتصفح؛ ثم ترجمه من قائمة «ترجمة» في المتصفح.
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
مهم

يحوّل التطبيق الملف ويفتحه افتراضيًا دون ترجمة مدفوعة. أما Google Cloud وOllama فوضعان منفصلان.

Windows protected your PC?

برنامج التثبيت والبرامج المحمولة غير موقّعة رقميًا، لذلك قد يوقف Windows SmartScreen التشغيل الأول. انقر More info ثم Run anyway (تظهر هاتان العبارتان مترجمتين في Windows العربي). نسخة Microsoft Store موقّعة من Microsoft ولا تُظهر هذه النافذة. لماذا يحدث ذلك، وما الذي لا يفعله التطبيق أبدًا (بالإنجليزية).
