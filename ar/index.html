doc-html-translate

GUI · CLI · Chromium extension

يحوّل ملفات EPUB وPDF وMOBI وFB2 وRTF وTXT وMarkdown وHTML والقصص المصورة والصور إلى HTML محلي مع فهرس وتنقّل. تُفتح النتيجة في المتصفح، حيث يمكن قراءة النص والبحث فيه وترجمته بترجمة الصفحة المدمجة. وللصور يتوفر التعرف الضوئي على الحروف.

# فيمَ يُستخدم

أربعة استخدامات رئيسية، دون الارتباط بقارئ بعينه أو بخدمة عبر الإنترنت.

READ

فتح كتاب أو مستند

الحصول على صفحة محلية بفهرس وتنقّل وسمات وموضع قراءة محفوظ.

TRANSLATE

الترجمة في المتصفح

افتح ملف HTML في Chrome أو Edge واستخدم ترجمة الصفحة الكاملة في المتصفح.

OCR

استخراج النص من صورة

إضافة طبقات نصية قابلة للترجمة إلى مسح ضوئي أو صورة أو صفحة قصة مصورة.

LOCAL

الاحتفاظ بالنتيجة محليًا

مجلد عادي يضم ملف HTML وموارده، يمكن نقله وإعادة فتحه.

# كيف يعمل

يقرأ التطبيق الملف المصدر، وينشئ ملف index.html محليًا، ثم يفتحه في المتصفح.

EPUB / PDF / FB2 / CBZ→local index.html→Chrome / Edge→قراءة وترجمة

# التثبيت والتشغيل

يُثبَّت تطبيق سطح المكتب والنسخة المحمولة والإضافة كل على حدة.

Microsoft Store GitHub Releases الإضافة
  1. ثبّت التطبيق أو نزّل النسخة المحمولة.
  2. افتح ملفًا مدعومًا من الواجهة أو من سطر الأوامر.
  3. ينشئ التطبيق ملف HTML ويفتحه في المتصفح.
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
مهم

يحوّل التطبيق الملف ويفتحه افتراضيًا دون ترجمة مدفوعة. أما Google Cloud وOllama فوضعان منفصلان.
