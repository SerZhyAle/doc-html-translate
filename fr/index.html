Tout livre, document ou bande dessinée en page web locale

Lisez-la, cherchez-y et traduisez-la avec la traduction de page du navigateur - gratuit, sans clé.

Pour tous ceux qui lisent des livres et des documents dans une autre langue : EPUB, PDF, MOBI, FB2, RTF, TXT, Markdown, HTML, bandes dessinées et images deviennent du HTML local avec table des matières et navigation. L'OCR est disponible pour les images.

EPUB / PDF / FB2 / CBZ / ..→local index.html→Chrome / Edge→lecture et traduction

Installation et lancement

L'application de bureau (fenêtre + ligne de commande) et l'extension du navigateur s'installent indépendamment. Toutes les options sont gratuites.

Microsoft Store GitHub Releases Programme d'installation setup.exe Chrome Web Store Edge Add-ons
  1. Installez l'application depuis le Microsoft Store, avec winget ou le programme d'installation - ou téléchargez l'archive zip portable depuis GitHub Releases.
  2. Ouvrez un fichier pris en charge dans la fenêtre de l'application ou avec la commande ci-dessous.
  3. L'application crée le HTML et l'ouvre dans le navigateur ; traduisez-le depuis le menu « Traduire » du navigateur.
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
Important

Par défaut, l'application convertit et ouvre le fichier sans traduction payante. Google Cloud et Ollama sont des modes distincts.

Windows protected your PC?

Le programme d'installation et les programmes portables ne sont pas signés, c'est pourquoi Windows SmartScreen peut bloquer le premier lancement. Cliquez sur More info, puis sur Run anyway (sous un Windows en français, ces libellés sont traduits). La version du Microsoft Store est signée par Microsoft et n'affiche pas cette fenêtre. Pourquoi, et ce que l'application ne fait jamais (en anglais).

# À quoi ça sert

Quatre usages principaux, sans dépendre d'une liseuse particulière ni d'un service en ligne.

READ

Ouvrir un livre ou un document

Obtenir une page locale avec table des matières, navigation, thèmes et position de lecture enregistrée.

TRANSLATE

Traduire dans le navigateur

Ouvrir le HTML dans Chrome ou Edge et utiliser la traduction de page du navigateur.

OCR

Reconnaître le texte d'une image

Ajouter des calques de texte traduisible à un scan, une image ou une planche de BD.

LOCAL

Conserver le résultat en local

Un dossier ordinaire avec le HTML et ses ressources, que l'on peut déplacer et rouvrir.

Quelque chose s'est mal passé ?

L'application peut empaqueter elle-même ses propres journaux d'exécution et ouvrir un message déjà adressé à l'auteur. Rien ne quitte votre machine tant que vous n'avez pas appuyé sur Envoyer.
