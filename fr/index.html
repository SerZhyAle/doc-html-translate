Convertisseur de documents pour Windows

doc-html-translate

GUI · CLI · Chromium extension

Convertit EPUB, PDF, MOBI, FB2, RTF, TXT, Markdown, HTML, bandes dessinées et images en HTML local avec table des matières et navigation. Le résultat s'ouvre dans le navigateur, où le texte peut être lu, recherché et traduit par la traduction de page intégrée. La reconnaissance de texte est disponible pour les images.

EPUBPDFMOBI / AZW3FB2RTFTXT / MD / HTMLCBZ / CBR / CB7 / CBTPNG / JPG / TIFF
Installation Extension Documentation GitHub

# À quoi ça sert

Quatre usages principaux, sans dépendre d'une liseuse particulière ni d'un service en ligne.

READ

Ouvrir un livre ou un document

Obtenir une page locale avec table des matières, navigation, thèmes et position de lecture enregistrée.

TRANSLATE

Traduire dans le navigateur

Ouvrir le HTML dans Chrome ou Edge et utiliser la traduction de page du navigateur.

OCR

Reconnaître le texte d'une image

Ajouter des calques de texte traduisible à un scan, une image ou une planche de BD.

LOCAL

Conserver le résultat en local

Un dossier ordinaire avec le HTML et ses ressources, que l'on peut déplacer et rouvrir.

# Comment ça marche

L'application lit le fichier source, crée un index.html local et l'ouvre dans le navigateur.

EPUB / PDF / FB2 / CBZ→local index.html→Chrome / Edge→lecture et traduction

# Installation et lancement

L'application de bureau, la version portable et l'extension s'installent indépendamment.

Microsoft Store GitHub Releases Extension
  1. Installez l'application ou téléchargez la version portable.
  2. Ouvrez un fichier pris en charge depuis l'interface ou la ligne de commande.
  3. L'application crée le HTML et l'ouvre dans le navigateur.
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
Important

Par défaut, l'application convertit et ouvre le fichier sans traduction payante. Google Cloud et Ollama sont des modes distincts.
