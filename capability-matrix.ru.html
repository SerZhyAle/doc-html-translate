# Режимы работы и их зависимости

РежимДля чего онЧто умеетНа чём работает
Окно приложенияОбычное конвертирование в окнеМеню из семи страниц сбоку, справка F1 по той части окна, где вы находитесь, размер текста и интерфейса, темы, перетаскивание файлов, очередь конвертации.Windows 10/11 (64-бит). Ничего сверх самого приложения ставить не нужно: pdftotext входит в его состав; необязательные программы из списка ниже используются, только когда файлу они нужны.
Командная строкаПовторяемые задачи, скрипты, запуск без участия человекаВсе параметры конвертации в виде флагов, свои папки вывода, выбор движка, коды возврата для скриптов.Исполняемый файл doc-html-translate; для стандартных текстовых и книжных форматов ничего ставить не нужно; те же необязательные программы по потребности.

Ничего не устанавливается.
Движки перевода (необязательные)Перевод готового текстаШтатный перевод страницы в браузере (бесплатно, без ключа); локальная модель Ollama; Google Cloud Translation с ограничителем расходов.Переводу страницы ничего дополнительного не нужно; Ollama нужен локальный сервер на localhost:11434; Google Cloud нужен ваш ключ API, а -max-cost отменяет запрос до отправки, если оценка превышает лимит.

# Форматы и нужные им программы

ФорматРасширения файловЧто нужно
Книги EPUB.epubНичего - встроенный разбор.
Документы PDF.pdfВ Windows - ничего: pdftotext входит в приложение; на других системах - установленный Poppler; при отсутствии - встроенный запасной разбор.
Книги Kindle.mobi, .azw3Установленный Calibre (файлы без DRM).
FictionBook.fb2Ничего - встроенный разбор.
Форматированный и простой текст.rtf, .txt, .md, .htmlНичего - встроенный разбор.
Комиксы (архивы zip и tar).cbz, .cbtНичего - распаковываются самим приложением.
Комиксы (архивы rar и 7z).cbr, .cb7Установленный 7-Zip.
Картинки и сканы.png, .jpg, .jpeg, .webp, .gif, .bmp, .tif, .tiffНеобязательно: внешний движок Tesseract для OCR; английские данные входят в приложение, другие языки скачиваются по запросу. Без него картинки сохраняются без текстовых плашек.
Картинки JPEG XL.jxlНичего - декодируются в самом приложении встроенным декодером.
Секретные файлы FileDO.fd-secУстановленная программа FileDO и пароль контейнера; расшифрованная копия удаляется сразу после чтения.
Полезно знать

OCR и необязательные программы - вспомогательные: отсутствие Tesseract или помощника никогда не прерывает конвертацию - шаг, которому они были нужны, переходит на запасной путь и сообщает об этом. Файлы с защитой DRM не поддерживаются.
