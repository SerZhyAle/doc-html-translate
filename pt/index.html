Qualquer livro, documento ou banda desenhada numa página web local

Leia, pesquise e traduza com a tradução de páginas do próprio navegador - grátis, sem chaves.

Para quem lê livros e documentos noutra língua: EPUB, PDF, MOBI, FB2, RTF, TXT, Markdown, HTML, banda desenhada e imagens tornam-se HTML local com índice e navegação. Para imagens há OCR.

EPUB / PDF / FB2 / CBZ / ..→local index.html→Chrome / Edge→leitura e tradução

Instalar e executar

A aplicação de ambiente de trabalho (janela + linha de comandos) e a extensão do navegador instalam-se de forma independente. Todas as opções são gratuitas.

Microsoft Store GitHub Releases Instalador setup.exe Chrome Web Store Edge Add-ons
  1. Instale a aplicação a partir da Microsoft Store, com o winget ou com o instalador - ou transfira o zip portable do GitHub Releases.
  2. Abra um ficheiro suportado na janela da aplicação ou com o comando abaixo.
  3. A aplicação cria o HTML e abre-o no navegador; traduza-o a partir do menu «Traduzir» do navegador.
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
Importante

Por predefinição, a aplicação converte e abre o ficheiro sem tradução paga. O Google Cloud e o Ollama são modos separados.

Windows protected your PC?

O instalador e os programas portáteis não têm assinatura digital, por isso o Windows SmartScreen pode bloquear a primeira execução. Clique em More info e depois em Run anyway (num Windows em português, estes textos aparecem traduzidos). A versão da Microsoft Store é assinada pela Microsoft e não mostra esta janela. # Para que serve

Quatro cenários principais, sem depender de um leitor específico nem de um serviço online.

READ

Abrir um livro ou documento

Obter uma página local com índice, navegação, temas e posição de leitura guardada.

TRANSLATE

Traduzir no navegador

Abrir o HTML no Chrome ou no Edge e usar a tradução de página do navegador.

OCR

Reconhecer o texto de uma imagem

Acrescentar camadas de texto traduzível a uma digitalização, imagem ou página de banda desenhada.

LOCAL

Manter o resultado localmente

Uma pasta normal com HTML e recursos, que se pode mover e voltar a abrir.

Algo correu mal?

A aplicação consegue empacotar por si mesma os seus próprios registos de execução e abrir uma mensagem já endereçada ao autor. Nada sai do seu computador até que carregue em Enviar.
