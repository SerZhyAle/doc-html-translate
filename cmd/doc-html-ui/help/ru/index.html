Справка

Короткие объяснения окна конвертера и вопросов, которые оно задаёт, с картинкой настоящего окна. Всё здесь работает без сети.

Окна и диалоги

  • DOC-HTML-UIОкноОкно конвертера: выберите файл, способ перевода и нажмите «Конвертировать».
  • НастройкиОкноOllama, OCR изображений, Windows, интерфейс, дополнительно и «О программе».
  • Платный переводДиалогВопрос, который задают перед оплатой Google.
  • Секретный файл FileDOДиалогВопрос о пароле для файла .fd-sec.
  • Конвертация не завершиласьДиалогЧто предлагает окно, когда запуск не удался.

Клавиши

F1
Справка о той части окна, где вы находитесь.
Ctrl + Enter
Конвертировать.
Esc
Отменить идущую конвертацию; закрыть вопрос.
Ctrl + Shift + F
Поставить клавиатурный фокус на поле файла.
