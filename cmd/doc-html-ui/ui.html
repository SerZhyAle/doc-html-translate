Convert

Converts e-books and documents into a local HTML book you can read and translate in the browser.

Add this app to Windows? You can get a "Convert to HTML" entry in the right-click menu of supported files and a place under "Open with", or also make it the default app for them. Nothing changes unless you pick it here or later under "Windows integration".
Supported: EPUB, MOBI, AZW3, FB2, PDF, TXT, Markdown, HTML, RTF, comics (CBZ/CBR/CB7/CBT), and images (PNG/JPG/WebP/..). MOBI/AZW3 need Calibre; CBR/CB7 need 7-Zip; image and comic text overlay needs Tesseract.

      Ollama

      Settings of the local Ollama translation engine.

      A model already pulled into your local Ollama; gemma3:12b is the default. A larger model translates better but needs more memory and runs slower.
      How many batches go to Ollama at once; 1 (the minimum) sends them one by one. More helps only when Ollama itself runs with OLLAMA_NUM_PARALLEL set to the same number, and costs memory.
      tokens
      The model's working window per request, in tokens: minimum 512, default 8192. Smaller is faster and uses less memory, but below about 4000 a batch of text may not fit; larger only costs memory.

      Image OCR

      Recognize text in pictures so that translation reaches it too.

      Recognizes text baked into images (EPUB/PDF pages, or a standalone image you open directly) and lays it over them as real text, so translation covers pictures too. A standalone image is OCR'd automatically. Needs Tesseract installed.

      English is built-in; download other languages as needed.
