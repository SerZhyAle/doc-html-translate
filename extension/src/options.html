doc-html-translate

General

Language, appearance and when documents are reflowed.

Re-renders documents (PDF, EPUB, MOBI, AZW3, FB2, RTF, TXT, Markdown, HTML) as clean, reflowed HTML so the browser's built-in "Translate page" works. Everything runs locally; the only thing that phones home is the browser's own translator - and only when you ask it to.

The language of this extension's own buttons and menus. "Follow the browser" uses your browser's language. Applies to the viewer the next time you open a document.

Colours of this page and the toolbar popup. "System" follows the browser's light or dark setting as it changes.

Auto-intercepts PDF, EPUB, MOBI, AZW3, FB2 and RTF links. When off, they open or download the way the browser normally handles them - i.e. back to square one. (Other formats always open via the file picker.)

Sets <html lang> so the browser offers the right translation. Auto-detect works for most documents (EPUBs also use their declared language) - and guesses right more often than not.

Image OCR

Recognize text in pictures so that translation reaches it too.

Recognize text baked into images - in your documents, and via the right-click "OCR & translate this image" - then translate it with the browser's "Translate page". English works offline; other languages download on demand and are cached locally.

Sites

Which websites get automatic reflow, and whether documents may load remote images.

Automatic reflow is off by default. Turn it on above, then choose which sites it applies to. Switching modes keeps both lists.

Sites where reflow is off
  • None

Manage these from the toolbar popup's "On this site" switch.

Sites where reflow is on in only listed sites mode
  • None

Manage these from the toolbar popup's "On this site" switch while only listed sites mode is selected.

Off by default: images a document pulls from the internet are blocked, so its author cannot see that you opened it. The viewer lets you load them for one document at a time.

Data

Back up, restore or reset every extension setting in one file.

Settings file

Exports extension options, interface language and both site lists. Reading positions, document content, OCR output and history are excluded. Reader text size and font remain in this browser profile.

Interface

How large the controls and the text are, and how they are operated.

Scales the buttons, options, headers and menu together - text, icons, spacing and click targets.

Enlarges the text first and the layout with it; the icons grow only moderately. It stacks with the interface size.

Touch makes every target larger. Automatic picks once when the window opens; it never changes while you work. Choose here on a device that has both.

About

The program, its version, help and where to get support.

Open PDF, EPUB and more as clean HTML that the browser's free Translate can read, with image OCR. Conversion happens locally.
