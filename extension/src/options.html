doc-html-translate

Re-renders PDFs and EPUBs as clean, reflowed HTML so the browser's built-in "Translate page" works. Everything runs locally; only the browser's own translate touches the network.

When off, PDFs open in the browser's native viewer and EPUBs download as usual.
