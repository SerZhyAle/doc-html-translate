Conversor de documentos para Windows · GUI · CLI · extensión de Chromium

Cualquier libro, documento o cómic, convertido en una página web local

Léelo, busca en él y tradúcelo con la traducción de páginas del propio navegador: gratis y sin claves.

Para quien lee libros y documentos en otro idioma: EPUB, PDF, MOBI, FB2, RTF, TXT, Markdown, HTML, cómics e imágenes se convierten en HTML local con índice y navegación. Para las imágenes hay OCR.

EPUB / PDF / FB2 / CBZ / ..→local index.html→Chrome / Edge→lectura y traducción

Instalación y uso

La aplicación de escritorio (ventana + línea de comandos) y la extensión del navegador se instalan por separado. Todas las opciones son gratuitas.

Microsoft Store GitHub Releases Instalador setup.exe Chrome Web Store Edge Add-ons
  1. Instala la aplicación desde Microsoft Store, con winget o con el instalador, o descarga el zip portable desde GitHub Releases.
  2. Abre un archivo compatible en la ventana de la aplicación o con el comando de abajo.
  3. La aplicación crea el HTML y lo abre en el navegador; tradúcelo desde el menú «Traducir» del navegador.
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
Importante

De forma predeterminada, la app convierte y abre el archivo sin traducción de pago. Google Cloud y Ollama son modos aparte.

Windows protected your PC?

El instalador y los programas portátiles no están firmados digitalmente, por lo que Windows SmartScreen puede detener el primer inicio. Haga clic en More info y luego en Run anyway (en un Windows en español, estos textos aparecen traducidos). La versión de Microsoft Store está firmada por Microsoft y no muestra esta ventana. # Para qué sirve

Cuatro escenarios principales, sin depender de un lector concreto ni de un servicio en línea.

READ

Abrir un libro o un documento

Obtener una página local con índice, navegación, temas y posición de lectura guardada.

TRANSLATE

Traducir en el navegador

Abrir el HTML en Chrome o Edge y usar la traducción de página del navegador.

OCR

Reconocer el texto de una imagen

Añadir capas de texto traducible a un escaneo, una imagen o una página de cómic.

LOCAL

Guardar el resultado en local

Una carpeta normal con HTML y recursos, que se puede mover y volver a abrir.
