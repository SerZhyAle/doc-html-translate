doc-html-translate

GUI · CLI · Chromium extension

Convierte EPUB, PDF, MOBI, FB2, RTF, TXT, Markdown, HTML, cómics e imágenes en HTML local con índice y navegación. El resultado se abre en el navegador, donde el texto se puede leer, buscar y traducir con la traducción de página integrada. Para las imágenes hay reconocimiento de texto.

# Para qué sirve

Cuatro escenarios principales, sin depender de un lector concreto ni de un servicio en línea.

READ

Abrir un libro o un documento

Obtener una página local con índice, navegación, temas y posición de lectura guardada.

TRANSLATE

Traducir en el navegador

Abrir el HTML en Chrome o Edge y usar la traducción de página del navegador.

OCR

Reconocer el texto de una imagen

Añadir capas de texto traducible a un escaneo, una imagen o una página de cómic.

LOCAL

Guardar el resultado en local

Una carpeta normal con HTML y recursos, que se puede mover y volver a abrir.

# Cómo funciona

La aplicación lee el archivo de origen, crea un index.html local y lo abre en el navegador.

EPUB / PDF / FB2 / CBZ→local index.html→Chrome / Edge→lectura y traducción

# Instalación y uso

La aplicación de escritorio, la versión portable y la extensión se instalan de forma independiente.

Microsoft Store GitHub Releases Extensión
  1. Instala la aplicación o descarga la versión portable.
  2. Abre un archivo compatible desde la interfaz o la línea de comandos.
  3. La aplicación crea el HTML y lo abre en el navegador.
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
Importante

De forma predeterminada, la app convierte y abre el archivo sin traducción de pago. Google Cloud y Ollama son modos aparte.
