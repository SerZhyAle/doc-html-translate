Почему Windows предупреждает об этом приложенииWhy Windows warns about this appЧому Windows попереджає про цей застосунок

Doc-HTML-Translate · обновлено 2026-09-25Doc-HTML-Translate · last updated 2026-09-25Doc-HTML-Translate · оновлено 2026-09-25

Doc-HTML-Translate - бесплатная программа с открытым исходным кодом от независимого разработчика. Установщик, portable-программы и пакет winget не подписаны сертификатом разработчика, поэтому при первом запуске Windows может показать синее окно «Windows protected your PC» (в русской Windows - «Система Windows защитила ваш компьютер»). Коротко: нажмите Подробнее, затем Выполнить в любом случае. Версия из Microsoft Store подписана Microsoft, и этого окна у неё нет.

Doc-HTML-Translate is a free, open-source tool from an independent developer. The setup installer, the portable programs and the winget package are not code-signed, so the first time you run one Windows may stop it with a blue "Windows protected your PC" window. The short answer: click More info, then Run anyway. The Microsoft Store version is signed by Microsoft and does not show this window.

Doc-HTML-Translate - безкоштовна програма з відкритим вихідним кодом від незалежного розробника. Інсталятор, portable-програми та пакет winget не підписані сертифікатом розробника, тому під час першого запуску Windows може показати синє вікно «Windows protected your PC» (в українській Windows - той самий текст українською). Коротко: натисніть посилання More info під текстом, потім кнопку Run anyway (в українській Windows обидва написи перекладені). Версія з Microsoft Store підписана Microsoft, і цього вікна в неї немає.

1. Что это за предупреждение1. What the warning is1. Що це за попередження

SmartScreen: «Windows protected your PC» / «Система Windows защитила ваш компьютер». Это окно показывает Microsoft Defender SmartScreen, когда вы впервые запускаете программу, которая не подписана сертификатом разработчика и которую Windows пока видела редко. В окне сказано, что SmartScreen предотвратил запуск неопознанного приложения, а издатель указан как «Неизвестный издатель». Это осторожность Windows по отношению к файлу, которого она ещё не знает, а не вывод о том, что файл вреден.

  • Установщик doc-html-translate-setup-<версия>.exe и portable-программы doc-html-translate-<версия>-windows-x64.exe, doc-html-ui-<версия>-windows-x64.exe (и они же из zip-архива) из GitHub Releases - окно может появиться.
  • winget (winget install SerZhyAle.DocHtmlTranslate) ставит ту же неподписанную portable-сборку - окно тоже может появиться.
  • Microsoft Store - нет: пакет подписывает Microsoft при сертификации.
  • Расширение для браузера - нет: оно ставится из Chrome Web Store или Edge Add-ons.

Браузер тоже может предупредить ещё при скачивании, что файл «скачивают нечасто». Это та же причина - файл не подписан и пока мало известен.

SmartScreen: "Windows protected your PC". Microsoft Defender SmartScreen shows this window the first time you run a program that is not signed with a code-signing certificate and that Windows has not yet seen often. The window says SmartScreen prevented an unrecognized app from starting, and lists the publisher as "Unknown publisher". It is Windows being cautious about a file it does not know yet, not a finding that the file is harmful.

  • The setup installer doc-html-translate-setup-<version>.exe and the portable programs doc-html-translate-<version>-windows-x64.exe, doc-html-ui-<version>-windows-x64.exe (and the same two inside the zip) from GitHub Releases - the window can appear.
  • winget (winget install SerZhyAle.DocHtmlTranslate) installs the same unsigned portable build - the window can appear too.
  • Microsoft Store - no: Microsoft signs the package when it certifies it.
  • The browser extension - no: it installs from the Chrome Web Store or Edge Add-ons.

Your browser may also warn while downloading that the file is "not commonly downloaded". Same reason: the file is unsigned and not yet widely known.

SmartScreen: «Windows protected your PC». Це вікно показує Microsoft Defender SmartScreen, коли ви вперше запускаєте програму, яка не підписана сертифікатом розробника і яку Windows поки що бачила рідко. У вікні сказано, що SmartScreen запобіг запуску нерозпізнаного застосунку, а видавця вказано як невідомого. Це обережність Windows щодо файлу, якого вона ще не знає, а не висновок, що файл шкідливий.

  • Інсталятор doc-html-translate-setup-<версія>.exe і portable-програми doc-html-translate-<версія>-windows-x64.exe, doc-html-ui-<версія>-windows-x64.exe (і вони ж із zip-архіву) з GitHub Releases - вікно може з'явитися.
  • winget (winget install SerZhyAle.DocHtmlTranslate) встановлює ту саму непідписану portable-збірку - вікно теж може з'явитися.
  • Microsoft Store - ні: пакет підписує Microsoft під час сертифікації.
  • Розширення для браузера - ні: воно встановлюється з Chrome Web Store або Edge Add-ons.

Браузер теж може попередити ще під час завантаження, що файл «завантажують нечасто». Причина та сама - файл не підписаний і поки що маловідомий.

2. Почему оно появляется2. Why it appears2. Чому воно з'являється

Сборка не подписана - и это был наш выбор. Сертификат для подписи кода стоит несколько сотен долларов в год. Программа бесплатна, без рекламы и без доходов, и пока мы решили на сертификат не тратиться. Предупреждение - это Windows, которая работает так, как задумано, а не ошибка и не что-то, чего вы не должны видеть.

Предупреждение со временем исчезает. SmartScreen накапливает репутацию каждого файла: чем больше людей скачивают и запускают выпуск, тем реже Windows о нём предупреждает. Каждая новая версия - это новый файл, поэтому сразу после обновления окно может появиться снова.

Как проверить, что файл настоящий. Исходный код открыт на GitHub. Скачивайте только со страницы релизов или через winget: winget сверяет контрольную сумму SHA-256 архива с манифестом в каталоге Microsoft winget-pkgs и не установит изменённый файл. Если хотите обойтись без предупреждения совсем - ставьте версию из Microsoft Store.

The build is not signed - and that was a choice. A code-signing certificate costs hundreds of dollars a year. The app is free, with no ads and no income, and for now we chose not to spend that. The warning is Windows working as designed, not a bug and not something you should not be seeing.

The warning fades. SmartScreen builds a reputation for each file: the more people download and run a release, the less often Windows warns about it. Each new version is a new file, so the window can come back right after an update.

How to check the file is genuine. The source code is open on GitHub. Download only from the releases page or through winget: winget checks the archive's SHA-256 against the manifest in Microsoft's winget-pkgs catalog and will not install a file that was changed. If you would rather not see the warning at all, install the Microsoft Store version.

Збірка не підписана - і це був наш вибір. Сертифікат для підпису коду коштує кілька сотень доларів на рік. Програма безкоштовна, без реклами й без доходів, і поки що ми вирішили на сертифікат не витрачатися. Попередження - це Windows, яка працює так, як задумано, а не помилка і не щось, чого ви не маєте бачити.

Попередження з часом зникає. SmartScreen накопичує репутацію кожного файлу: що більше людей завантажують і запускають випуск, то рідше Windows про нього попереджає. Кожна нова версія - це новий файл, тому одразу після оновлення вікно може з'явитися знову.

Як перевірити, що файл справжній. Вихідний код відкритий на GitHub. Завантажуйте лише зі сторінки релізів або через winget: winget звіряє контрольну суму SHA-256 архіву з маніфестом у каталозі Microsoft winget-pkgs і не встановить змінений файл. Якщо хочете обійтися без попередження взагалі - встановлюйте версію з Microsoft Store.

3. Что именно нажать3. Exactly what to click3. Що саме натиснути

В окне «Windows protected your PC» / «Система Windows защитила ваш компьютер»:

  1. Нажмите ссылку Подробнее (More info) под текстом.
  2. Проверьте строку «Приложение» (App): там должно быть имя скачанного файла - doc-html-translate-setup-<версия>.exe, doc-html-ui-*.exe или doc-html-translate-*.exe.
  3. Нажмите кнопку Выполнить в любом случае (Run anyway) - она появляется внизу только после первого шага.

Это всё. Windows запомнит этот файл и больше не спросит о нём.

Второго окна не будет. Установщику не нужны права администратора: он ставит программу в ваш профиль (%LOCALAPPDATA%\Programs\doc-html-translate), поэтому окна «Разрешить этому приложению вносить изменения?» он не вызывает.

Если браузер не даёт сохранить файл, откройте меню этой загрузки на панели загрузок и выберите «Сохранить» (Keep); Edge переспросит ещё раз - «Показать больше», затем «Всё равно сохранить».

Если антивирус поместил файл в карантин, добавьте исключение только для одной папки программы - %LOCALAPPDATA%\Programs\doc-html-translate или папки, куда вы распаковали portable-версию. Отключать антивирус не нужно.

Мы никогда не попросим вас отключить SmartScreen, отключить антивирус или запускать программу от имени администратора.

In the "Windows protected your PC" window:

  1. Click the More info link under the text.
  2. Check the App line: it should name the file you downloaded - doc-html-translate-setup-<version>.exe, doc-html-ui-*.exe or doc-html-translate-*.exe.
  3. Click the Run anyway button - it appears at the bottom only after step 1.

That is all. Windows remembers this file and will not ask about it again.

No second prompt follows. The installer needs no administrator rights: it installs into your user profile (%LOCALAPPDATA%\Programs\doc-html-translate), so it raises no "Do you want to allow this app to make changes?" window.

If your browser will not keep the download, open that download's menu in the downloads panel and choose Keep; Edge asks once more - Show more, then Keep anyway.

If your antivirus quarantines the file, add an exception for the one program folder only - %LOCALAPPDATA%\Programs\doc-html-translate, or the folder you unzipped the portable version into. There is no need to turn the antivirus off.

We will never ask you to turn off SmartScreen, disable your antivirus, or run the app as administrator.

У вікні «Windows protected your PC» (в українській Windows - той самий текст українською):

  1. Натисніть посилання More info під текстом (в українській Windows воно перекладене).
  2. Перевірте рядок App (застосунок): там має бути ім'я завантаженого файлу - doc-html-translate-setup-<версія>.exe, doc-html-ui-*.exe або doc-html-translate-*.exe.
  3. Натисніть кнопку Run anyway - вона з'являється внизу лише після першого кроку.

Це все. Windows запам'ятає цей файл і більше про нього не питатиме.

Другого вікна не буде. Інсталятору не потрібні права адміністратора: він встановлює програму у ваш профіль (%LOCALAPPDATA%\Programs\doc-html-translate), тому вікна з питанням, чи дозволити цьому застосунку вносити зміни, він не викликає.

Якщо браузер не дає зберегти файл, відкрийте меню цього завантаження на панелі завантажень і виберіть збереження (Keep); Edge перепитає ще раз - Show more, потім Keep anyway.

Якщо антивірус помістив файл у карантин, додайте виняток лише для однієї теки програми - %LOCALAPPDATA%\Programs\doc-html-translate або теки, куди ви розпакували portable-версію. Вимикати антивірус не потрібно.

Ми ніколи не попросимо вас вимкнути SmartScreen, вимкнути антивірус чи запускати програму від імені адміністратора.

4. Чего приложение никогда не делает4. What the app never does4. Чого застосунок ніколи не робить

  • Никогда не собирает, не хранит, не записывает в журналы и не передаёт персональные данные. Нет телеметрии, аналитики, рекламы, учётных записей и собственных серверов.
  • Никогда не отправляет ваши документы сам по себе. Текст покидает компьютер, только если вы явно выберете перевод через Google Cloud со своим ключом; в режиме Ollama он уходит только на сервер на вашем же компьютере. При бесплатном переводе в браузере, который используется по умолчанию, приложение ничего не отправляет.
  • Никогда не выгружает журналы. Кнопка «Отправить журналы автору» только собирает архив на вашем диске и готовит неотправленное письмо - отправляете его вы сами.
  • Никогда не просит прав администратора и не принимает подключения с других компьютеров. Окно приложения общается со своим движком только через адрес 127.0.0.1 на вашем же компьютере.
  • Никогда не назначает себя программой по умолчанию без вашей просьбы. Установщик лишь добавляет её в список «Открыть с помощью» и пункт «Convert to HTML» в контекстном меню - этот флажок можно снять, а удаление программы убирает эти записи.
  • It never collects, stores, logs or transmits personal data. No telemetry, analytics, ads, accounts or servers of its own.
  • It never sends your documents anywhere by itself. Text leaves your computer only if you explicitly choose Google Cloud translation with your own key; with Ollama it goes only to a server on your own machine. With the default free browser translation the app sends nothing.
  • It never uploads its logs. The Send logs to the author button only builds an archive on your disk and prepares an unsent message - you send it yourself.
  • It never asks for administrator rights and never accepts connections from other computers. The app window talks to its own engine only through 127.0.0.1 on your own PC.
  • It never makes itself the default program unless you ask. The installer only adds it to the "Open with" list and the right-click "Convert to HTML" entry - a checkbox you can clear - and uninstalling removes those entries.
  • Ніколи не збирає, не зберігає, не записує до журналів і не передає персональних даних. Немає телеметрії, аналітики, реклами, облікових записів і власних серверів.
  • Ніколи не надсилає ваші документи сам по собі. Текст покидає комп'ютер, лише якщо ви явно оберете переклад через Google Cloud зі своїм ключем; у режимі Ollama він іде лише на сервер на вашому ж комп'ютері. За безкоштовного перекладу в браузері, який використовується типово, застосунок нічого не надсилає.
  • Ніколи не вивантажує журнали. Кнопка «Надіслати журнали авторові» лише збирає архів на вашому диску й готує ненадісланий лист - надсилаєте його ви самі.
  • Ніколи не просить прав адміністратора й не приймає з'єднань з інших комп'ютерів. Вікно застосунку спілкується зі своїм рушієм лише через адресу 127.0.0.1 на вашому ж комп'ютері.
  • Ніколи не призначає себе програмою за замовчуванням без вашого прохання. Інсталятор лише додає її до списку «Відкрити за допомогою» та пункту «Convert to HTML» у контекстному меню - цей прапорець можна зняти, а видалення програми прибирає ці записи.
