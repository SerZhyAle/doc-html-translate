Встановлення

Настільний застосунок (вікно + командний рядок) і розширення для браузера встановлюються незалежно. Усі варіанти безкоштовні.

Microsoft Store GitHub Releases v26.1112.2325 Що нового Інсталятор setup.exe Chrome Web Store v26.1021.41 Edge Add-ons v26.1021.41
  1. Встановіть застосунок із Microsoft Store, через winget або інсталятором - чи завантажте portable-архів із GitHub Releases.
  2. Відкрийте підтримуваний файл у вікні застосунку або командою нижче.
  3. Застосунок створить HTML і відкриє його у браузері; переклад - через меню браузера «Перекласти».
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
Важливо

Типово застосунок конвертує й відкриває файл без платного перекладу. Google Cloud та Ollama - окремі режими.

Windows protected your PC?

Інсталятор і portable-програми не підписані сертифікатом розробника, тому Windows SmartScreen може зупинити перший запуск. Натисніть More info, потім Run anyway (в українській Windows - їхній переклад). Версія з Microsoft Store підписана Microsoft і цього вікна не показує. Чому так і чого застосунок ніколи не робить.

# Що нового

Нове: зображення JPEG XL - відкрийте .jxl-файл або книжку чи комікс із зображеннями JPEG XL: вони декодуються локально вбудованим декодером і потім показуються, розпізнаються та перекладаються, як будь-яке інше зображення. Нічого додатково встановлювати не потрібно.

Нове: вікно з меню із семи сторінок - вікно застосунку перебудовано: збоку меню із семи сторінок, а на сторінці «Інтерфейс» - розмір інтерфейсу, розмір текста та режим миші або дотику. F1 або кнопка «?» відкриває довідку про ту частину вікна, де ви перебуваєте (англійською, російською та українською).

# Для чого потрібен

Чотири основні сценарії без прив’язки до конкретної читалки чи онлайн-сервісу.

READ

Відкрити книжку чи документ

Отримати локальну сторінку зі змістом, навігацією, темами й збереженням позиції.

TRANSLATE

Перекласти у браузері

Відкрити HTML у Chrome або Edge й використати штатний переклад усієї сторінки.

OCR

Розпізнати текст на зображенні

Додати перекладні текстові шари до скану, зображення чи сторінки коміксу. Плашки закривають літери, які замінюють, а кнопка у шапці ховає весь шар, щоб подивитися малюнок під ним.

LOCAL

Зберегти результат локально

Звичайна тека з HTML і ресурсами; її можна переносити й відкривати повторно.

Застосунок уміє сам запакувати свої журнали запусків і відкрити готового листа авторові. Ніщо не покидає комп'ютер, доки ви не натиснете «Надіслати».
