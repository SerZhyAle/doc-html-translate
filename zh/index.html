Windows 文档转换器

doc-html-translate

GUI · CLI · Chromium extension

把 EPUB、PDF、MOBI、FB2、RTF、TXT、Markdown、HTML、漫画和图片转换为带目录与导航的本地 HTML。结果在浏览器中打开，可以阅读、搜索，并用浏览器内置的页面翻译进行翻译。图片支持文字识别。

EPUBPDFMOBI / AZW3FB2RTFTXT / MD / HTMLCBZ / CBR / CB7 / CBTPNG / JPG / TIFF
安装 扩展 文档 GitHub

# 用途

四种主要场景，不依赖特定阅读器或在线服务。

READ

打开图书或文档

得到一个本地页面，带目录、导航、主题和阅读位置记忆。

TRANSLATE

在浏览器中翻译

在 Chrome 或 Edge 中打开 HTML，使用浏览器的整页翻译。

OCR

识别图片中的文字

为扫描件、图片或漫画页添加可翻译的文字层。

LOCAL

把结果留在本地

一个普通的文件夹，内含 HTML 与资源，可以移动并重新打开。

# 工作方式

程序读取源文件，生成本地的 index.html 并在浏览器中打开。

EPUB / PDF / FB2 / CBZ→local index.html→Chrome / Edge→阅读与翻译

# 安装与运行

桌面应用、便携版和扩展分别独立安装。

Microsoft Store GitHub Releases 扩展
  1. 安装应用，或下载便携版。
  2. 通过界面或命令行打开受支持的文件。
  3. 应用生成 HTML 并在浏览器中打开。
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
重要

默认情况下，应用只转换并打开文件，不使用付费翻译。Google Cloud 与 Ollama 是单独的模式。
