Doc-HTML-Translate.Windows 文档转换器 · GUI · CLI · Chromium 扩展

把任何书籍、文档或漫画变成本地网页

用浏览器自带的页面翻译阅读、搜索和翻译，免费，无需密钥。

为用其他语言阅读书籍和文档的人而做：EPUB、PDF、MOBI、FB2、RTF、TXT、Markdown、HTML、漫画和图片会变成带目录与导航的本地 HTML。图片支持 OCR 文字识别。

新功能：FileDO 加密文件 - 打开 .fd-sec 文件：应用会询问密码，使用您电脑上已安装的 FileDO 解密，并像处理原文件一样转换其中的文档或图片。解密后的副本会立即删除；转换后的页面不加密。

EPUB / PDF / FB2 / CBZ / ..→local index.html→Chrome / Edge→阅读与翻译

安装与运行

桌面应用（窗口 + 命令行）和浏览器扩展分别独立安装。所有方式均免费。

Microsoft Store GitHub Releases 版本说明 安装程序 setup.exe Chrome Web Store Edge Add-ons
  1. 从 Microsoft Store、通过 winget 或安装程序安装应用，也可以从 GitHub Releases 下载便携版 zip。
  2. 在应用窗口中打开受支持的文件，或使用下方命令。
  3. 应用生成 HTML 并在浏览器中打开；通过浏览器的“翻译”菜单进行翻译。
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
重要

默认情况下，应用只转换并打开文件，不使用付费翻译。Google Cloud 与 Ollama 是单独的模式。

Windows protected your PC?

安装程序和便携版程序没有代码签名，因此 Windows SmartScreen 可能会拦截首次运行。请点击 More info，然后点击 Run anyway（中文版 Windows 中这两处文字已译成中文）。Microsoft Store 版本由 Microsoft 签名，不会出现此窗口。原因说明，以及本应用绝不会做的事（英文）。

# 用途

四种主要场景，不依赖特定阅读器或在线服务。

READ

打开图书或文档

得到一个本地页面，带目录、导航、主题和阅读位置记忆。

TRANSLATE

在浏览器中翻译

在 Chrome 或 Edge 中打开 HTML，使用浏览器的整页翻译。

OCR

识别图片中的文字

为扫描件、图片或漫画页添加可翻译的文字层。

LOCAL

把结果留在本地

一个普通的文件夹，内含 HTML 与资源，可以移动并重新打开。
