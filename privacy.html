Doc-HTML-Translate · обновлено 2026-09-25Doc-HTML-Translate · last updated 2026-09-25Doc-HTML-Translate · оновлено 2026-09-25

Doc-HTML-Translate не собирает, не хранит, не записывает в журналы и не передаёт никаких персональных данных. Приложение работает полностью на вашем устройстве, не имеет собственных серверов и не содержит телеметрии, аналитики, рекламы и учётных записей.

Doc-HTML-Translate does not collect, store, log, or transmit any personal data. It runs entirely on your device, has no servers of its own, and contains no telemetry, analytics, ads, or accounts.

Doc-HTML-Translate не збирає, не зберігає, не записує до журналів і не передає жодних персональних даних. Застосунок працює повністю на вашому пристрої, не має власних серверів і не містить телеметрії, аналітики, реклами чи облікових записів.

К чему приложение обращается и зачемWhat it accesses and whyДо чого застосунок звертається і навіщо

  • Файлы документов, которые вы открываете - чтобы преобразовать их в локальный HTML.
  • Ваш браузер - чтобы показать преобразованный HTML, а для настольного приложения - и его собственное окно.
  • Соединение только внутри вашего компьютера - настольное приложение общается со своим окном через 127.0.0.1 под защитой секрета, который создаётся заново при каждом запуске, и закрывает соединение вместе с окном. Через него ничто не покидает ваше устройство.
  • Интернет, для перевода через Google - только если вы явно его выберете: извлечённый текст отправляется в Google Cloud Translation API с ключом, который вы предоставляете сами.
  • Локальный сервер Ollama - только если вы выберете вариант Ollama: текст отправляется на сервер перевода на вашем собственном компьютере (localhost:11434) и больше никуда.
  • GitHub, для дополнительных языков OCR - только когда вы скачиваете язык (Скачать в приложении или -ocr-download): файл данных языка загружается из открытого репозитория tessdata_fast проекта Tesseract и сверяется с закреплённым отпечатком SHA-256. Запрос называет только язык; ничего вашего не отправляется. Английский встроен.
  • Сопоставления файлов Windows - только если вы их выберете, по умолчанию выключено: записи для вашей учётной записи, чтобы документ открывался двойным щелчком, через пункт Convert to HTML в контекстном меню или через Открыть с помощью. При удалении восстанавливается прежний обработчик.
  • Вспомогательные программы на вашем компьютере - встроенный pdftotext для PDF, а также Tesseract, Calibre, 7-Zip, ffmpeg или ImageMagick, если вы их установили, запускаются локально, чтобы прочитать формат. Приложение ничего не устанавливает.
  • Ваша почтовая программа - только когда вы нажмёте Отправить журналы автору: приложение открывает в ней неотправленное письмо и само ничего не отправляет (см. ниже).
  • The document files you open - to convert them to local HTML.
  • Your web browser - to display the converted HTML, and, for the desktop app, its own window.
  • A connection inside your computer only - the desktop app talks to its own window over 127.0.0.1, guarded by a secret made anew at each launch, and closes it with the window. Nothing leaves your device through it.
  • The internet, for Google translation - only if you explicitly choose it: the extracted text is sent to the Google Cloud Translation API using a key you supply.
  • A local Ollama server - only if you choose the Ollama option: the text is sent to the translation server on your own machine (localhost:11434), nowhere else.
  • GitHub, for extra OCR languages - only when you download one (Download in the app, or -ocr-download): the language's data file is fetched from the Tesseract project's public tessdata_fast repository and checked against a pinned SHA-256 digest. The request names the language; nothing of yours is sent. English is built in.
  • Windows file associations - only if you choose them, off by default: per-user entries so that double-clicking a document, the right-click Convert to HTML entry or Open with reach the app. Removing them restores the handler you had before.
  • Helper programs on your computer - the bundled pdftotext for PDF, and Tesseract, Calibre, 7-Zip, ffmpeg or ImageMagick where you have installed them, run locally to read a format. The app never installs anything.
  • Your mail program - only when you press Send logs to the author: the app opens an unsent message there and never sends anything itself (see below).
  • Файли документів, які ви відкриваєте - щоб перетворити їх на локальний HTML.
  • Ваш браузер - щоб показати перетворений HTML, а для настільного застосунку - і його власне вікно.
  • З'єднання лише всередині вашого комп'ютера - настільний застосунок спілкується зі своїм вікном через 127.0.0.1 під захистом секрету, що створюється заново під час кожного запуску, і закриває з'єднання разом із вікном. Через нього ніщо не залишає ваш пристрій.
  • Інтернет, для перекладу через Google - лише якщо ви явно його оберете: видобутий текст надсилається до Google Cloud Translation API з ключем, який ви надаєте самі.
  • Локальний сервер Ollama - лише якщо ви оберете варіант Ollama: текст надсилається на сервер перекладу на вашому власному комп'ютері (localhost:11434) і більше нікуди.
  • GitHub, для додаткових мов OCR - лише коли ви завантажуєте мову (Завантажити в застосунку або -ocr-download): файл даних мови завантажується з відкритого репозиторію tessdata_fast проєкту Tesseract і звіряється із закріпленим відбитком SHA-256. Запит називає лише мову; нічого вашого не надсилається. Англійська вбудована.
  • Зіставлення файлів Windows - лише якщо ви їх оберете, типово вимкнено: записи для вашого облікового запису, щоб документ відкривався подвійним клацанням, через пункт Convert to HTML у контекстному меню або через Відкрити за допомогою. Під час видалення відновлюється попередній обробник.
  • Допоміжні програми на вашому комп'ютері - вбудований pdftotext для PDF, а також Tesseract, Calibre, 7-Zip, ffmpeg чи ImageMagick, якщо ви їх встановили, запускаються локально, щоб прочитати формат. Застосунок нічого не встановлює.
  • Ваша поштова програма - лише коли ви натиснете Надіслати журнали авторові: застосунок відкриває в ній ненадісланий лист і сам нічого не надсилає (див. нижче).

При бесплатном переводе в браузере, который используется по умолчанию, приложение вообще ничего не отправляет.

With the default free browser translation, the app sends nothing at all.

За безкоштовного перекладу в браузері, який використовується типово, застосунок узагалі нічого не надсилає.

Локальные файлы, которые записывает приложениеLocal files it writesЛокальні файли, які записує застосунок

  • Преобразованный HTML - рядом с исходным файлом или в выбранной вами папке, вместе с небольшой записью о том, как он был сделан, чтобы неизменённая книга открывалась повторно, а не пересобиралась.
  • Папка приложения вашей учётной записи (%LOCALAPPDATA%\doc-html-translate) - ваши настройки, необязательный ключ Google API, который вы сохраняете, журналы последних запусков, скачанные языки OCR и распакованная копия встроенного pdftotext.
  • The converted HTML - next to the source file, or in a folder you choose, with a small record of how it was made so that an unchanged book is reopened instead of rebuilt.
  • Your per-user app folder (%LOCALAPPDATA%\doc-html-translate) - your settings, the optional Google API key you save, the recent run logs, downloaded OCR languages and an unpacked copy of the bundled pdftotext.
  • Перетворений HTML - поруч із вихідним файлом або в обраній вами теці, разом із невеликим записом про те, як його зроблено, щоб незмінена книжка відкривалася повторно, а не перебудовувалася.
  • Тека застосунку вашого облікового запису (%LOCALAPPDATA%\doc-html-translate) - ваші налаштування, необов'язковий ключ Google API, який ви зберігаєте, журнали останніх запусків, завантажені мови OCR і розпакована копія вбудованого pdftotext.

Эти файлы никогда не покидают ваше устройство.

These files never leave your device.

Ці файли ніколи не залишають ваш пристрій.

Отправка журналов авторуSending logs to the authorНадсилання журналів авторові

Приложение хранит журналы последних запусков на вашем собственном диске и, только когда вы сами об этом попросите (кнопка Отправить журналы автору в разделе «О программе» или -report в командной строке), упаковывает их вместе с кратким описанием окружения - версия, редакция, платформа, язык интерфейса, доступен ли OCR - и параметрами последнего запуска в один архив в %LOCALAPPDATA%\doc-html-translate\reports\. Всё, что похоже на ключ, токен, пароль или ключ Google API, заменяется на <redacted> ещё до попадания в архив, а пути к вашим папкам сокращаются до %USERPROFILE% и %LOCALAPPDATA%. Ключа Google Cloud Translation API в архиве никогда нет.

Архив остаётся на вашем диске. Приложение никогда не выгружает его и не открывает для него никаких сетевых соединений. Оно открывает папку с архивом, помещает путь к нему в буфер обмена и составляет неотправленное письмо автору в вашей собственной почтовой программе - вы сами прикладываете архив и нажимаете «Отправить»; при этом вы можете сначала открыть архив или в любой момент очистить сохранённые журналы.

The app keeps its recent run logs on your own disk and, only when you ask for it (the Send logs to the author button in the About section, or -report on the command line), packs them with a short environment summary - version, edition, platform, interface language, whether OCR is available - and the last run's settings into one archive under %LOCALAPPDATA%\doc-html-translate\reports\. Anything that looks like a key, a token, a password or a Google API key becomes <redacted> before it reaches the archive, and your folder paths are reduced to %USERPROFILE% and %LOCALAPPDATA%. The Google Cloud Translation API key is never in it.

The archive stays on your disk. The app never uploads it and opens no network connection for it. It opens the archive's folder, puts the path on your clipboard, and composes an unsent message in your own mail program addressed to the author - you attach the archive and press Send yourself, and you can open the archive first or clear the stored logs at any time.

Застосунок зберігає журнали останніх запусків на вашому власному диску і, лише коли ви самі про це попросите (кнопка Надіслати журнали авторові в розділі «Про програму» або -report у командному рядку), пакує їх разом із коротким описом середовища - версія, редакція, платформа, мова інтерфейсу, чи доступний OCR - та параметрами останнього запуску в один архів у %LOCALAPPDATA%\doc-html-translate\reports\. Усе, що схоже на ключ, токен, пароль або ключ Google API, замінюється на <redacted> ще до потрапляння в архів, а шляхи до ваших тек скорочуються до %USERPROFILE% і %LOCALAPPDATA%. Ключа Google Cloud Translation API в архіві ніколи немає.

Архів залишається на вашому диску. Застосунок ніколи не вивантажує його й не відкриває для нього жодного мережевого з'єднання. Він відкриває теку з архівом, копіює шлях до нього в буфер обміну й складає ненадісланий лист авторові у вашій власній поштовій програмі - ви самі додаєте архів і натискаєте «Надіслати»; при цьому ви можете спершу відкрити архів або будь-коли очистити збережені журнали.
