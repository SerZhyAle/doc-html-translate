Политика конфиденциальностиPrivacy PolicyПолітика конфіденційності

Doc-HTML-Translate · обновлено 2026-08-11Doc-HTML-Translate · last updated 2026-08-11Doc-HTML-Translate · оновлено 2026-08-11

Doc-HTML-Translate не собирает, не хранит, не записывает в журналы и не передаёт никаких персональных данных. Приложение работает полностью на вашем устройстве, не имеет собственных серверов и не содержит телеметрии, аналитики, рекламы и учётных записей.

Doc-HTML-Translate does not collect, store, log, or transmit any personal data. It runs entirely on your device, has no servers of its own, and contains no telemetry, analytics, ads, or accounts.

Doc-HTML-Translate не збирає, не зберігає, не записує до журналів і не передає жодних персональних даних. Застосунок працює повністю на вашому пристрої, не має власних серверів і не містить телеметрії, аналітики, реклами чи облікових записів.

К чему приложение обращается и зачемWhat it accesses and whyДо чого застосунок звертається і навіщо

  • Файлы документов, которые вы открываете - чтобы преобразовать их в локальный HTML.
  • Ваш браузер - чтобы показать преобразованный HTML.
  • Интернет - только если вы явно выберете перевод через Google: извлечённый текст отправляется в Google Cloud Translation API с ключом, который вы предоставляете сами. В локальном режиме Ollama текст отправляется только на сервер перевода, работающий на вашем собственном компьютере. При бесплатном переводе в браузере, который используется по умолчанию, приложение вообще ничего не отправляет.
  • The document files you open - to convert them to local HTML.
  • Your web browser - to display the converted HTML.
  • The internet - only if you explicitly choose Google translation: the extracted text is sent to the Google Cloud Translation API using a key you supply. With the local Ollama option, text is sent only to a translation server running on your own machine. With the default free browser translation, nothing is sent by the app at all.
  • Файли документів, які ви відкриваєте - щоб перетворити їх на локальний HTML.
  • Ваш браузер - щоб показати перетворений HTML.
  • Інтернет - лише якщо ви явно оберете переклад через Google: видобутий текст надсилається до Google Cloud Translation API з ключем, який ви надаєте самі. У локальному режимі Ollama текст надсилається лише на сервер перекладу, що працює на вашому власному комп'ютері. За безкоштовного перекладу в браузері, який використовується типово, застосунок узагалі нічого не надсилає.

Локальные файлы, которые записывает приложениеLocal files it writesЛокальні файли, які записує застосунок

Преобразованный HTML (рядом с исходным файлом или в выбранной вами папке) и необязательный файл с API-ключом, который вы размещаете сами. Эти файлы никогда не покидают ваше устройство.

The converted HTML output (next to the source file, or in a folder you choose), and an optional API key file you place yourself. These never leave your device.

Перетворений HTML (поруч із вихідним файлом або в обраній вами теці) і необов'язковий файл з API-ключем, який ви розміщуєте самі. Ці файли ніколи не залишають ваш пристрій.

Отправка журналов авторуSending logs to the authorНадсилання журналів авторові

Приложение хранит журналы последних запусков на вашем собственном диске и, только когда вы сами об этом попросите (кнопка Отправить журналы автору в разделе «О программе» или -report в командной строке), упаковывает их вместе с кратким описанием окружения - версия, редакция, платформа, язык интерфейса, доступен ли OCR - и параметрами последнего запуска в один архив в %LOCALAPPDATA%\doc-html-translate\reports\. Всё, что похоже на ключ, токен, пароль или ключ Google API, заменяется на <redacted> ещё до попадания в архив, а пути к вашим папкам сокращаются до %USERPROFILE% и %LOCALAPPDATA%. Ключа Google Cloud Translation API в архиве никогда нет.

Архив остаётся на вашем диске. Приложение никогда не выгружает его и не открывает для него никаких сетевых соединений. Оно открывает папку с архивом, помещает путь к нему в буфер обмена и составляет неотправленное письмо автору в вашей собственной почтовой программе - вы сами прикладываете архив и нажимаете «Отправить»; при этом вы можете сначала открыть архив или в любой момент очистить сохранённые журналы.

The app keeps its recent run logs on your own disk and, only when you ask for it (the Send logs to the author button in the About section, or -report on the command line), packs them with a short environment summary - version, edition, platform, interface language, whether OCR is available - and the last run's settings into one archive under %LOCALAPPDATA%\doc-html-translate\reports\. Anything that looks like a key, a token, a password or a Google API key becomes <redacted> before it reaches the archive, and your folder paths are reduced to %USERPROFILE% and %LOCALAPPDATA%. The Google Cloud Translation API key is never in it.

The archive stays on your disk. The app never uploads it and opens no network connection for it. It opens the archive's folder, puts the path on your clipboard, and composes an unsent message in your own mail program addressed to the author - you attach the archive and press Send yourself, and you can open the archive first or clear the stored logs at any time.

Застосунок зберігає журнали останніх запусків на вашому власному диску і, лише коли ви самі про це попросите (кнопка Надіслати журнали авторові в розділі «Про програму» або -report у командному рядку), пакує їх разом із коротким описом середовища - версія, редакція, платформа, мова інтерфейсу, чи доступний OCR - та параметрами останнього запуску в один архів у %LOCALAPPDATA%\doc-html-translate\reports\. Усе, що схоже на ключ, токен, пароль або ключ Google API, замінюється на <redacted> ще до потрапляння в архів, а шляхи до ваших тек скорочуються до %USERPROFILE% і %LOCALAPPDATA%. Ключа Google Cloud Translation API в архіві ніколи немає.

Архів залишається на вашому диску. Застосунок ніколи не вивантажує його й не відкриває для нього жодного мережевого з'єднання. Він відкриває теку з архівом, копіює шлях до нього в буфер обміну й складає ненадісланий лист авторові у вашій власній поштовій програмі - ви самі додаєте архів і натискаєте «Надіслати»; при цьому ви можете спершу відкрити архів або будь-коли очистити збережені журнали.
