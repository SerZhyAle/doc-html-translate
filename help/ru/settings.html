Справка по окну

Настройки

Настройки окна лежат на страницах, список которых стоит в начале окна. Выберите страницу, и её настройки появятся на месте; окно помнит, на какой странице вы были. В узком окне тот же список открывается кнопкой «Страницы».

По порядку

У этой части нет обязательного порядка; её элементы сгруппированы по темам ниже.

Элементы

1ДополнительноРазбивка книги на блоки, глубина оглавления и предел стоимости.
  • Размер блока - Символов на блок; 0 отключает разбиение. Если сомневаетесь - 0.
  • Глубина оглавления / Макс. стоимость - Глубина оглавления: 0 = без ограничений, 1 = только главы. Макс. стоимость (только платные движки): 0 = без лимита; напр. 2 пропустит Google, если оценка превысит $2 (книга всё равно конвертируется, без перевода).
Зачем
Значения по умолчанию подходят почти любой книге; меняйте их, только если книга огромна, оглавление слишком глубокое или нужен потолок для платного перевода.
Что дальше
Значение используется со следующей конвертации и видно в командной строке.
Отмена
Верните в поле 0.
2OllamaЛокальная модель, которая переводит, когда выбран движок Ollama.
  • Модель - Модель, уже скачанная в ваш локальный Ollama; по умолчанию gemma3:12b. Модель побольше переводит лучше, но требует больше памяти и работает медленнее.
  • Параллельно - Сколько пакетов уходит в Ollama одновременно; 1 (минимум) отправляет их по одному. Больше помогает, только если сам Ollama запущен с OLLAMA_NUM_PARALLEL, равным тому же числу, и стоит памяти.
  • Контекст - Рабочее окно модели на один запрос, в токенах: минимум 512, по умолчанию 8192. Меньше - быстрее и экономнее по памяти, но ниже примерно 4000 пакет текста может не поместиться; больше - только расход памяти.
Зачем
Это важно только с движком Ollama; с любым другим они игнорируются.
Что дальше
Значения попадают в командную строку, только если выбран Ollama и они отличаются от значений по умолчанию.
Отмена
Верните значения по умолчанию: gemma3:12b, 1 и 8192.
3OCR картинокДелает текст внутри картинок доступным для перевода.
  • Наложить переводимый текст поверх изображений - Распознаёт текст, впечатанный в изображения (в EPUB/PDF или в отдельном файле-картинке, открытом напрямую), и накладывает его поверх как настоящий текст, чтобы перевод охватывал и картинки. Отдельная картинка распознаётся автоматически. Нужен установленный Tesseract.
  • Язык OCR - На каком языке распознаватель читает текст. «Автоматически» следует исходному языку.
  • Добавить язык / Скачать - Английский встроен; другие языки скачивайте по необходимости.
Зачем
У отсканированных страниц, комиксов и картинок нет текста для перевода, пока его не распознали.
Что дальше
Распознанный текст накладывается на каждую картинку как настоящий текст. Кнопка со знаком вопроса рядом с параметром полностью объясняет оба состояния. Загрузка языковых данных - единственное на этой странице, что требует интернета; перед сохранением файл сверяется с опубликованной контрольной суммой.
Отмена
Снимите отметку наложения для следующей конвертации. Готовые результаты сохраняют текстовый слой, пока их не пересоберут.
Осторожно

Для наложения нужен установленный Tesseract. Когда его нет, об этом говорит строка состояния под полем файла.

4WindowsНеобязательные связи программы с Windows; обе выключены, пока вы их не включите.
  • Пункт правого клика «Convert to HTML» и «Открыть с помощью» - По желанию. Добавляет команду «Convert to HTML» в меню правого клика поддерживаемых файлов и показывает приложение в списке «Открыть с помощью». Программы по умолчанию остаются прежними.
  • Сделать обработчиком по умолчанию для EPUB, PDF, .. - По желанию и выключено по умолчанию. Двойной щелчок по документу будет открывать его этим приложением (ассоциации файлов для текущего пользователя).
  • Открыть «Приложения по умолчанию» - Открывает страницу Windows, где последнее слово о приложениях по умолчанию - за вами.
Зачем
Они экономят шаг: щёлкните книгу правой кнопкой и конвертируйте её или дважды щёлкните, чтобы открыть здесь.
Что дальше
Windows может и дальше открывать тип файла программой, выбранной ранее; тогда эта страница сообщает об этом, и изменить это можете только вы. В издании из Microsoft Store этой страницы нет: оно само ничего не регистрирует в Windows.
Отмена
Выключите тот же пункт снова; программа убирает то, что добавила.
5ИнтерфейсНасколько крупны элементы и текст и для мыши или для касания сделано окно.
  • Размер интерфейса - Масштабирует кнопки, параметры, заголовки и меню вместе: текст, значки, отступы и области нажатия.
  • Размер текста - Сначала увеличивает текст, а вместе с ним и раскладку; значки растут лишь умеренно. Складывается с размером интерфейса.
  • Управление - Сенсорный режим делает все области нажатия крупнее. «Автоматически» выбирает один раз при открытии окна и не меняется по ходу работы. На устройстве с обоими способами выберите здесь.
Зачем
Крупный интерфейс увеличивает вместе все кнопки, параметры, заголовки и строки меню; крупный текст сначала увеличивает надписи. Выберите то, что удобно читать и нажимать на вашем экране.
Что дальше
Изменение применяется сразу и запоминается. Ничего не конвертируется и не перезапускается, а окно не меняет собственный размер.
Отмена
Снова выберите «Обычный» и «Автоматически».
6О программеЧто установлено, обновления, вспомогательные программы, связанные продукты и способ попросить помощи с проблемой.
  • Версия / Издание / Лицензия - Версия, портативное это издание или из Microsoft Store, и лицензия (MIT).
  • Справка / Сайт программы / Конфиденциальность / Текст лицензии / Исходный код - Содержание справки, сайт программы, страница о конфиденциальности, текст лицензии и исходный код.
  • Обновления / Проверить обновления / Проверять автоматически (раз в день) - Проверяет канал обновлений раз в день и только сообщает - ничего не скачивается и не устанавливается без вас.
  • Поддержка и диагностика / Отправить журналы автору - Архив выделен в папке, а путь к нему скопирован в буфер обмена - прикрепите его к письму перед отправкой.
  • Очистить журналы - Удаляет сохранённые журналы запусков, предварительно спросив. Число сохранённых журналов показано над кнопками.
  • Ресурсы / Движок конвертера - Что программе нужно для работы и где это взять. Ничего не устанавливается за вас.
  • Связанные продукты - Все проекты того же автора
Зачем
Когда конвертация не удалась, журналы помогают автору найти причину. Само ничего не отправляется: вы прикладываете архив к письму. Открытие этой страницы ни к чему в интернете не обращается.
Что дальше
Проверка обновлений только сообщает о новой версии; без вас ничего не скачивается и не устанавливается. В издании из Microsoft Store обновляет Store, и проверка не показывается. Группа «Ресурсы» говорит, какие вспомогательные программы найдены на этом компьютере; её ссылки «Скачать» открывают сайты самих программ.
Отмена
Очистка сохранённых журналов сначала спрашивает и необратима; после неё журналы уже нельзя отправить.
