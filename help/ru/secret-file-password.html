Секретный файл FileDO

Файл .fd-sec - зашифрованный контейнер FileDO. Конвертер спрашивает пароль, открывает его через FileDO и конвертирует содержимое.

По порядку

  1. Введите пароль 2. Точки скрывают его по мере набора.
  2. Нажмите Открыть 3 или Enter. Если пароль неверный, вопрос вернётся с пояснением, и можно попробовать другой.
  3. Чтобы оставить файл в покое, нажмите Отмена 4 или Esc.

Элементы

1Справка (F1)Открывает эту страницу, не закрывая вопрос.

Вопрос остаётся открытым и ждёт, пока вы читаете. F1 делает то же самое.

2ПарольПустой пароль открывает только файл, сделанный без пароля - это лишь маскировка, а не секретность.

Введите пароль, с которым сделан файл. Поле показывает точки, а набранное передаётся только FileDO: оно не попадает ни в журнал, ни в командную строку, ни в какой-либо файл. Расшифровывает FileDO, а открытая копия, которую он делает во временной папке, удаляется, как только конвертер её прочитал.

Зачем
Контейнер зашифрован; без пароля конвертировать нечего.
Что дальше
В очереди пароль, введённый для первого контейнера, предлагается следующим без повторного вопроса; контейнер, который он не открыл, спрашивает свой.
Отмена
Очистите поле и введите заново. После закрытия вопроса ничего не запоминается.
Осторожно

Для открытия секретного файла нужен установленный FileDO: winget install SerZhyAle.FileDO или FileDO из Microsoft Store. Когда его нет, об этом говорит строка состояния под полем файла.

3ОткрытьПередаёт пароль FileDO и, если файл открылся, конвертирует его содержимое.

Если пароль не открыл файл, вопрос возвращается с пояснением: пароль может быть неверным, файл - не секретным файлом FileDO или изменённым.

Клавиши
Enter в поле делает то же самое.
4ОтменаОставляет файл закрытым; ничего не записывается.

Конвертация этого файла прекращается. В очереди остальные файлы продолжают идти. Закрыть вопрос или нажать Esc - тот же ответ.

Отмена
Конвертируйте файл снова, чтобы вопрос задали ещё раз.
Клавиши
Esc
