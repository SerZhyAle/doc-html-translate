FileDO secret file

A .fd-sec file is an encrypted FileDO container. The converter asks for its password, opens it with FileDO and converts what is inside.

In this order

  1. Type the password 2. The dots hide it as you type.
  2. Press Open 3 or Enter. If the password is wrong the question comes back with a note, and you can try another.
  3. To leave the file alone, press Cancel 4 or Esc.

The elements

1Help (F1)Opens this page without closing the question.

The question stays open and waits while you read. F1 does the same.

2PasswordAn empty password opens only a file made without one - obfuscation, no secrecy.

Type the password the file was made with. The field shows dots, and what you type is passed to FileDO only: it is not written to the log, the command line or any file. FileDO does the decrypting and the plain copy it makes in a temporary folder is deleted as soon as the converter has read it.

Why
The container is encrypted; without the password there is nothing to convert.
Next
In a queue, the password you type for the first container is offered to the next ones without asking again; a container it does not open asks for its own.
Undo
Clear the field and type again. Nothing is remembered after the question closes.
Careful

Opening a secret file needs FileDO installed: winget install SerZhyAle.FileDO, or FileDO from the Microsoft Store. The status line under the file box says when it is missing.

3OpenGives the password to FileDO and, if it opens the file, converts what is inside.

If the password does not open the file, the question comes back saying so: the password may be wrong, the file may not be a FileDO secret file, or it may have been altered.

Shortcut
Enter in the field does the same.
4CancelLeaves the file unopened; nothing is written.

The conversion of this file stops. In a queue the other files go on. Closing the question or pressing Esc is the same answer.

Undo
Convert the file again to be asked again.
Shortcut
Esc
