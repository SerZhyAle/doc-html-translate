Секретний файл FileDO

Файл .fd-sec - зашифрований контейнер FileDO. Конвертер питає пароль, відкриває його через FileDO і конвертує вміст.

По порядку

  1. Введіть пароль 2. Крапки ховають його під час набору.
  2. Натисніть Відкрити 3 або Enter. Якщо пароль хибний, питання повернеться з поясненням, і можна спробувати інший.
  3. Щоб лишити файл у спокої, натисніть Скасувати 4 або Esc.

Елементи

1Довідка (F1)Відкриває цю сторінку, не закриваючи питання.

Питання лишається відкритим і чекає, поки ви читаєте. F1 робить те саме.

2ПарольПорожній пароль відкриває лише файл, зроблений без пароля - це лише маскування, а не таємність.

Введіть пароль, з яким зроблено файл. Поле показує крапки, а набране передається лише FileDO: воно не потрапляє ні до журналу, ні до командного рядка, ні до будь-якого файла. Розшифровує FileDO, а відкрита копія, яку він робить у тимчасовій теці, видаляється, щойно конвертер її прочитав.

Навіщо
Контейнер зашифровано; без пароля конвертувати нічого.
Що далі
У черзі пароль, введений для першого контейнера, пропонується наступним без повторного питання; контейнер, який він не відкрив, питає свій.
Скасування
Очистіть поле й введіть заново. Після закриття питання нічого не запам'ятовується.
Обережно

Для відкриття секретного файла потрібен установлений FileDO: winget install SerZhyAle.FileDO або FileDO зі Microsoft Store. Коли його немає, про це каже рядок стану під полем файла.

3ВідкритиПередає пароль FileDO і, якщо файл відкрився, конвертує його вміст.

Якщо пароль не відкрив файл, питання повертається з поясненням: пароль може бути хибним, файл - не секретним файлом FileDO або зміненим.

Клавіші
Enter у полі робить те саме.
4СкасуватиЛишає файл закритим; нічого не записується.

Конвертація цього файла припиняється. У черзі решта файлів іде далі. Закрити питання чи натиснути Esc - та сама відповідь.

Скасування
Конвертуйте файл знову, щоб питання поставили ще раз.
Клавіші
Esc
