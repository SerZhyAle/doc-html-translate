Qualsiasi libro, documento o fumetto diventa una pagina web locale

Leggilo, cercaci dentro e traducilo con la traduzione di pagina del browser - gratis, senza chiavi.

Per chi legge libri e documenti in un'altra lingua: EPUB, PDF, MOBI, FB2, RTF, TXT, Markdown, HTML, fumetti e immagini diventano HTML locale con indice e navigazione. Per le immagini è disponibile l'OCR.

EPUB / PDF / FB2 / CBZ / ..→local index.html→Chrome / Edge→lettura e traduzione

Installazione e avvio

L'applicazione desktop (finestra + riga di comando) e l'estensione del browser si installano in modo indipendente. Tutte le opzioni sono gratuite.

Microsoft Store GitHub Releases Programma di installazione setup.exe Chrome Web Store Edge Add-ons
  1. Installa l'applicazione dal Microsoft Store, con winget o con il programma di installazione, oppure scarica l'archivio zip portable da GitHub Releases.
  2. Apri un file supportato nella finestra dell'applicazione o con il comando qui sotto.
  3. L'applicazione crea l'HTML e lo apre nel browser; per tradurlo usa il menu «Traduci» del browser.
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
Importante

Per impostazione predefinita l'app converte e apre il file senza traduzione a pagamento. Google Cloud e Ollama sono modalità separate.

Windows protected your PC?

Il programma di installazione e i programmi portatili non sono firmati digitalmente, quindi Windows SmartScreen può bloccare il primo avvio. Fai clic su More info e poi su Run anyway (in un Windows in italiano queste voci sono tradotte). La versione del Microsoft Store è firmata da Microsoft e non mostra questa finestra. Perché, e cosa l'app non fa mai (in inglese).

# A cosa serve

Quattro scenari principali, senza dipendere da un lettore o da un servizio online specifico.

READ

Aprire un libro o un documento

Ottenere una pagina locale con indice, navigazione, temi e posizione di lettura salvata.

TRANSLATE

Tradurre nel browser

Aprire l'HTML in Chrome o Edge e usare la traduzione di pagina del browser.

OCR

Riconoscere il testo in un'immagine

Aggiungere livelli di testo traducibile a una scansione, a un'immagine o a una pagina di fumetto.

LOCAL

Conservare il risultato in locale

Una normale cartella con HTML e risorse, che si può spostare e riaprire.

Lingue dell'interfaccia

L'interfaccia dell'applicazione e dell'estensione è disponibile in 13 lingue. Tranne inglese, russo e ucraino, tutte le traduzioni sono automatiche e non revisionate - le correzioni sono benvenute a sza@ukr.net.

Qualcosa non ha funzionato?

L'applicazione può impacchettare da sola i propri registri di esecuzione e aprire un messaggio già indirizzato all'autore. Nulla lascia il vostro computer finché non premete Invia.
