Dokumentkonverter für Windows · GUI · CLI · Chromium-Erweiterung

Jedes Buch, Dokument oder Comic als lokale Webseite

Lesen, durchsuchen und mit der Seitenübersetzung des Browsers übersetzen - kostenlos, ohne Schlüssel.

Für alle, die Bücher und Dokumente in einer anderen Sprache lesen: EPUB, PDF, MOBI, FB2, RTF, TXT, Markdown, HTML, Comics und Bilder werden zu lokalem HTML mit Inhaltsverzeichnis und Navigation. Für Bilder steht Texterkennung (OCR) bereit.

EPUB / PDF / FB2 / CBZ / ..→local index.html→Chrome / Edge→Lesen und Übersetzen

Installieren und starten

Die Desktop-Anwendung (Fenster + Befehlszeile) und die Browser-Erweiterung werden unabhängig voneinander installiert. Alle Varianten sind kostenlos.

Microsoft Store GitHub Releases Installationsprogramm setup.exe Chrome Web Store Edge Add-ons
  1. Installieren Sie die Anwendung aus dem Microsoft Store, mit winget oder dem Installationsprogramm - oder laden Sie das portable ZIP-Archiv von GitHub Releases herunter.
  2. Öffnen Sie eine unterstützte Datei im Anwendungsfenster oder mit dem Befehl unten.
  3. Die Anwendung erzeugt das HTML und öffnet es im Browser; übersetzt wird über das Menü „Übersetzen“ des Browsers.
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
Wichtig

Standardmäßig konvertiert und öffnet die App die Datei ohne kostenpflichtige Übersetzung. Google Cloud und Ollama sind separate Modi.

Windows protected your PC?

Das Installationsprogramm und die portablen Programme sind nicht codesigniert, daher kann Windows SmartScreen den ersten Start anhalten. Klicken Sie auf More info und dann auf Run anyway (in einem deutschen Windows stehen dort die deutschen Bezeichnungen). Die Version aus dem Microsoft Store ist von Microsoft signiert und zeigt dieses Fenster nicht. Warum - und was die App niemals tut (auf Englisch).

# Wofür es da ist

Vier Hauptszenarien, ohne an einen bestimmten Reader oder Onlinedienst gebunden zu sein.

READ

Ein Buch oder Dokument öffnen

Eine lokale Seite mit Inhaltsverzeichnis, Navigation, Themes und gespeicherter Leseposition erhalten.

TRANSLATE

Im Browser übersetzen

Das HTML in Chrome oder Edge öffnen und die Seitenübersetzung des Browsers verwenden.

OCR

Text in einem Bild erkennen

Übersetzbare Textebenen zu einem Scan, einem Bild oder einer Comicseite hinzufügen.

LOCAL

Das Ergebnis lokal behalten

Ein ganz normaler Ordner mit HTML und Ressourcen, der sich verschieben und erneut öffnen lässt.

Etwas ist schiefgelaufen?

Die Anwendung kann ihre eigenen Ausführungsprotokolle selbst verpacken und eine bereits adressierte Nachricht an den Autor öffnen. Nichts verlässt Ihren Rechner, bevor Sie auf Senden drücken.
