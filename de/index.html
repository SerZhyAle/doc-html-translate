doc-html-translate

GUI · CLI · Chromium extension

Wandelt EPUB, PDF, MOBI, FB2, RTF, TXT, Markdown, HTML, Comics und Bilder in lokales HTML mit Inhaltsverzeichnis und Navigation um. Das Ergebnis öffnet sich im Browser, wo der Text gelesen, durchsucht und mit der integrierten Seitenübersetzung übersetzt werden kann. Für Bilder steht Texterkennung bereit.

Installation Erweiterung Dokumentation GitHub

# Wofür es da ist

Vier Hauptszenarien, ohne an einen bestimmten Reader oder Onlinedienst gebunden zu sein.

READ

Ein Buch oder Dokument öffnen

Eine lokale Seite mit Inhaltsverzeichnis, Navigation, Themes und gespeicherter Leseposition erhalten.

TRANSLATE

Im Browser übersetzen

Das HTML in Chrome oder Edge öffnen und die Seitenübersetzung des Browsers verwenden.

OCR

Text in einem Bild erkennen

Übersetzbare Textebenen zu einem Scan, einem Bild oder einer Comicseite hinzufügen.

LOCAL

Das Ergebnis lokal behalten

Ein ganz normaler Ordner mit HTML und Ressourcen, der sich verschieben und erneut öffnen lässt.

# Wie es funktioniert

Die Anwendung liest die Quelldatei, erzeugt eine lokale index.html und öffnet sie im Browser.

EPUB / PDF / FB2 / CBZ→local index.html→Chrome / Edge→Lesen und Übersetzen

# Installieren und starten

Desktop-Anwendung, portable Version und Erweiterung werden unabhängig voneinander installiert.

Microsoft Store GitHub Releases Erweiterung
  1. Installieren Sie die Anwendung oder laden Sie die portable Version herunter.
  2. Öffnen Sie eine unterstützte Datei über die Oberfläche oder die Befehlszeile.
  3. Die Anwendung erzeugt HTML und öffnet es im Browser.
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
Wichtig

Standardmäßig konvertiert und öffnet die App die Datei ohne kostenpflichtige Übersetzung. Google Cloud und Ollama sind separate Modi.
