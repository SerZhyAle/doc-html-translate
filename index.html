02Перевод и OCRTranslation and OCRПереклад та OCR

Безопасный базовый сценарий — локальная конвертация и перевод страницы силами браузера. Режим -google использует Google Cloud Translation API; ограничитель -max-cost отменяет запрос до отправки, если оценка превышает заданную сумму. -ollama использует локальную модель. Для изображений и OCR-слоёв нужен внешний Tesseract; если его нет, конвертация не прерывается.The safe base route is local conversion and browser page translation. -google uses Google Cloud Translation API; -max-cost stops a request before sending when its estimate exceeds your limit. -ollama uses a local model. Images and OCR overlays need external Tesseract; if it is absent, conversion still completes.Безпечний базовий шлях — локальна конвертація та переклад сторінки силами браузера. -google використовує Google Cloud Translation API; -max-cost зупиняє запит до відправлення, якщо оцінка перевищує вказану суму. -ollama використовує локальну модель. Для зображень та OCR-шарів потрібен зовнішній Tesseract; без нього конвертація все одно завершується.
