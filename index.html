# What's new in 26.1112.2325Что нового в 26.1112.2325Що нового в 26.1112.2325

  • A new option beside the convert button, "And close this window", closes the window after a successful run or a finished queue (warnings count as success); after an error or a cancel the window stays open, and the choice is remembered.
  • Text recognition, in the desktop app and in the browser extension: a line with one oversized word - a drop cap, a display-type word, a tall letter - is no longer cut apart, so the word stays in its own line.
  • The diagnostic archive has a report.txt with the labelled facts, and environment.txt is KEY=value lines; the names of your documents are hidden in the run logs, and the settings copy leaves out the output folder and the recent documents. A run log over 5 MB keeps its first 1 MB and its last 4 MB or so. The extension copies and saves the diagnostics as one JSON file.
  • A FileDO secret file whose inner file name this computer cannot create now gets an exact message in every interface language: the file was opened, nothing was converted, the original is unchanged, open it with FileDO itself.
  • Windows: helper programs the app starts in the background, such as text recognition, run without a console window.
  • Closing the app window no longer leaves the app process running for another ten minutes because of the help map the window requests at start.
  • Рядом с кнопкой запуска конвертации появилась опция «И закрыть это окно»: окно закрывается после успешного запуска или завершённой очереди (предупреждения считаются успехом), а после ошибки или отмены остаётся открытым; выбор запоминается.
  • Распознавание текста в приложении и в расширении: строка с одним крупным словом - буквицей, заголовочным шрифтом, высокой буквой - больше не разрезается, слово остаётся в своей строке.
  • В диагностическом архиве появился файл report.txt с подписанными фактами, а environment.txt записан строками КЛЮЧ=значение; названия ваших документов в журналах скрыты, а копия настроек не содержит папку вывода и недавние документы. Журнал больше 5 МБ хранит первый мегабайт и последние около 4 МБ. Расширение копирует и сохраняет диагностику одним JSON-файлом.
  • Секретный файл FileDO, внутреннее имя которого этот компьютер не может создать, теперь получает точное сообщение на каждом языке интерфейса: файл открыт, ничего не сконвертировано, исходный файл не изменён, откройте его самим FileDO.
  • Windows: вспомогательные программы, которые приложение запускает в фоне (например, распознавание текста), работают без окна консоли.
  • Закрытое окно приложения больше не оставляет процесс работать ещё десять минут из-за карты справки, которую окно запрашивает при запуске.
  • Поруч із кнопкою запуску конвертації з'явилася опція «І закрити це вікно»: вікно закривається після успішного запуску або завершеної черги (попередження вважаються успіхом), а після помилки чи скасування залишається відкритим; вибір запам'ятовується.
  • Розпізнавання тексту в застосунку й у розширенні: рядок з одним великим словом - буквицею, заголовковим шрифтом, високою літерою - більше не розрізається, слово залишається у своєму рядку.
  • У діагностичному архіві з'явився файл report.txt із підписаними фактами, а environment.txt записано рядками КЛЮЧ=значення; назви ваших документів у журналах приховано, а копія налаштувань не містить теку виводу та нещодавні документи. Журнал понад 5 МБ зберігає перший мегабайт і останні близько 4 МБ. Розширення копіює й зберігає діагностику одним JSON-файлом.
  • Секретний файл FileDO, внутрішню назву якого цей комп'ютер не може створити, тепер отримує точне повідомлення кожною мовою інтерфейсу: файл відкрито, нічого не сконвертовано, початковий файл не змінено, відкрийте його самим FileDO.
  • Windows: допоміжні програми, які застосунок запускає у фоні (наприклад, розпізнавання тексту), працюють без вікна консолі.
  • Закрите вікно застосунку більше не залишає процес працювати ще десять хвилин через мапу довідки, яку вікно запитує під час запуску.

Translation and OCRПеревод и OCRПереклад та OCR

The safe base route is local conversion and browser page translation. -google uses Google Cloud Translation API; -max-cost stops a request before sending when its estimate exceeds your limit. -ollama uses a local model. Images and OCR overlays need external Tesseract; if it is absent, conversion still completes.Безопасный базовый сценарий - локальная конвертация и перевод страницы силами браузера. Режим -google использует Google Cloud Translation API; ограничитель -max-cost отменяет запрос до отправки, если оценка превышает заданную сумму. -ollama использует локальную модель. Для изображений и OCR-слоёв нужен внешний Tesseract; если его нет, конвертация не прерывается.Безпечний базовий шлях - локальна конвертація та переклад сторінки силами браузера. -google використовує Google Cloud Translation API; -max-cost зупиняє запит до відправлення, якщо оцінка перевищує вказану суму. -ollama використовує локальну модель. Для зображень та OCR-шарів потрібен зовнішній Tesseract; без нього конвертація все одно завершується.
