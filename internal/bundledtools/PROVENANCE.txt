Bundled pdftotext set - internal/bundledtools/pdftotext/

This file sits beside the pdftotext/ folder, not inside it: pdftotext_windows.go embeds that
folder whole, so a text file placed there would ship inside the executable and change the
content hash that names the unpacked cache folder (cache.go).

Origin: unmodified binaries of Git for Windows, taken from its mingw64/bin folder when the set was
vendored (commit 0954513, 2026-04-22). Re-read 2026-09-25: all four files are byte-identical to the
same files of Git for Windows 2.53.0.windows.2 on the build machine, whose etc/package-versions.txt
names the MSYS2 packages below, and the GCC build strings inside the binaries agree.

  pdftotext.exe         mingw-w64-x86_64-xpdf-tools 4.00-1. `pdftotext -v`: "pdftotext version 4.00,
                        Copyright 1996-2017 Glyph & Cog, LLC". Built by MSYS2 with GCC 7.3.0 (Rev2).
                        Git for Windows build recipe: https://github.com/git-for-windows/MINGW-packages
                        folder mingw-w64-xpdf (its history holds the 4.00-1 revision).
  libstdc++-6.dll       mingw-w64-x86_64-gcc-libs 15.2.0-11 (GCC 15.2.0, MSYS2 Rev11).
  libgcc_s_seh-1.dll    mingw-w64-x86_64-gcc-libs 15.2.0-11 (GCC 15.2.0, MSYS2 Rev11).
  libwinpthread-1.dll   mingw-w64-x86_64-libwinpthread 13.0.0.r488.g3fedac280-2.

Licences: Xpdf - GPL v2 or v3 (its README), GCC runtime - GPL v3 or later with the GCC Runtime
Library Exception 3.1, winpthreads - MIT-style plus a 3-clause BSD notice for the parts derived from
Lockless Inc. The texts ship in THIRD-PARTY-NOTICES.txt at the repository root, which every Windows
channel stages beside the executables.

All four files are tracked in git (.gitignore re-includes them past its *.exe rule), so a clean
checkout and the CI release build embed the same set as a local build. Until 2026-09-26 only the
DLLs were tracked and the CI-built assets shipped without pdftotext.exe (ticket 35). A build that
lacks pdftotext.exe reports ErrNotBundled and falls back to a pdftotext installed on the system;
.github/workflows/release.yml refuses to build when any file of the table below is missing or
differs from its hash. tests/bundled_notices_test.go holds every file present in pdftotext/ to a
line below and to a mention in THIRD-PARTY-NOTICES.txt, and none of them to a git-ignore rule.
