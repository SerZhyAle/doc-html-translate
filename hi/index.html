Windows के लिए दस्तावेज़ कनवर्टर · GUI · CLI · Chromium एक्सटेंशन

कोई भी किताब, दस्तावेज़ या कॉमिक - एक स्थानीय वेब पेज में

उसे पढ़ें, उसमें खोजें और ब्राउज़र के अपने पृष्ठ अनुवाद से अनुवाद करें - मुफ़्त, बिना किसी कुंजी के।

उन सभी के लिए जो किताबें और दस्तावेज़ किसी दूसरी भाषा में पढ़ते हैं: EPUB, PDF, MOBI, FB2, RTF, TXT, Markdown, HTML, कॉमिक्स और छवियाँ विषय-सूची और नेविगेशन सहित स्थानीय HTML बन जाती हैं। छवियों के लिए OCR उपलब्ध है।

EPUB / PDF / FB2 / CBZ / ..→local index.html→Chrome / Edge→पढ़ना और अनुवाद

इंस्टॉल और उपयोग

डेस्कटॉप एप्लिकेशन (विंडो + कमांड लाइन) और ब्राउज़र एक्सटेंशन अलग-अलग इंस्टॉल होते हैं। सभी विकल्प मुफ़्त हैं।

Microsoft Store GitHub Releases setup.exe इंस्टॉलर Chrome Web Store Edge Add-ons
  1. एप्लिकेशन को Microsoft Store से, winget से या इंस्टॉलर से इंस्टॉल करें - या GitHub Releases से portable zip डाउनलोड करें।
  2. समर्थित फ़ाइल को एप्लिकेशन की विंडो में या नीचे दिए गए कमांड से खोलें।
  3. एप्लिकेशन HTML बनाकर उसे ब्राउज़र में खोल देता है; अनुवाद ब्राउज़र के “अनुवाद करें” मेनू से करें।
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
महत्वपूर्ण

डिफ़ॉल्ट रूप से ऐप फ़ाइल को बिना सशुल्क अनुवाद के बदलता और खोलता है। Google Cloud और Ollama अलग मोड हैं।

Windows protected your PC?

सेटअप इंस्टॉलर और पोर्टेबल प्रोग्राम कोड-साइन नहीं हैं, इसलिए Windows SmartScreen पहली बार चलाने पर उन्हें रोक सकता है। More info पर क्लिक करें, फिर Run anyway पर (हिंदी Windows में ये शब्द अनुवादित दिखते हैं)। Microsoft Store वाला संस्करण Microsoft द्वारा साइन किया गया है और यह विंडो नहीं दिखाता। ऐसा क्यों होता है, और ऐप कभी क्या नहीं करता (अंग्रेज़ी में)।

इंटरफ़ेस की भाषाएँ

एप्लिकेशन और एक्सटेंशन का इंटरफ़ेस 13 भाषाओं में उपलब्ध है। अंग्रेज़ी, रूसी और यूक्रेनी को छोड़कर सभी अनुवाद मशीन से किए गए और अ-प्रूफ़रीड हैं - सुधार यहाँ भेजें: sza@ukr.net.

कुछ गड़बड़ हो गई?
