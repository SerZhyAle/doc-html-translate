# यह कैसे काम करता है

एप्लिकेशन स्रोत फ़ाइल पढ़ता है, स्थानीय index.html बनाता है और उसे ब्राउज़र में खोलता है।

EPUB / PDF / FB2 / CBZ→local index.html→Chrome / Edge→पढ़ना और अनुवाद

# इंस्टॉल और उपयोग

डेस्कटॉप एप्लिकेशन, portable संस्करण और एक्सटेंशन अलग-अलग इंस्टॉल होते हैं।

Microsoft Store GitHub Releases एक्सटेंशन
  1. एप्लिकेशन इंस्टॉल करें या portable संस्करण डाउनलोड करें।
  2. समर्थित फ़ाइल को इंटरफ़ेस या कमांड लाइन से खोलें।
  3. एप्लिकेशन HTML बनाकर उसे ब्राउज़र में खोल देता है।

# दस्तावेज़ीकरण और लिंक

पूरी मार्गदर्शिका अंग्रेज़ी, रूसी और यूक्रेनी में उपलब्ध है।

अंग्रेज़ी में दस्तावेज़ीकरण · ब्राउज़र एक्सटेंशन का पृष्ठ · एप्लिकेशन की गोपनीयता · एक्सटेंशन की गोपनीयता · GitHub पर स्रोत कोड

इंटरफ़ेस की भाषाएँ

एप्लिकेशन और एक्सटेंशन का इंटरफ़ेस 13 भाषाओं में उपलब्ध है। अंग्रेज़ी, रूसी और यूक्रेनी को छोड़कर सभी अनुवाद मशीन से किए गए और अ-प्रूफ़रीड हैं - सुधार यहाँ भेजें: sza@ukr.net.

कुछ गड़बड़ हो गई?

एप्लिकेशन अपने रन लॉग स्वयं एक संग्रह में पैक कर सकता है और लेखक के पते पर पहले से तैयार संदेश खोल सकता है। जब तक आप भेजें नहीं दबाते, कुछ भी आपके कंप्यूटर से बाहर नहीं जाता।
