# Pointer: CONTEXT-HELP

- **Id:** `CONTEXT-HELP`
- **Version:** 0.1 draft
- **Home:** the shared contracts catalog, `in-app-help/README.md` (its path is in [`AGENTS.md`](../../AGENTS.md))
- **Role:** consumer - the GUI launcher (`cmd/doc-html-ui`), adopted 2026-10-20 (ticket 118); `partial` until the owner's walk
- **Wire carrier:** none - a key, a button, a help map file and a page anatomy

F1 asks for help, a `?` button in the top-right corner asks as well, and both open the same page of the surface the
user is in. The GUI is an HTML page in an Edge or Chrome `--app` window, so the guidance for a browser application
(contract section 2.5) is the one that applies. What the repo holds, rule by rule:

- **Rules 1 and 3 - the key, one answer.** `cmd/doc-html-ui/help.js` registers one capture-phase `keydown` handler for
  bare F1 on the page itself, never system-wide. It asks about the dialog in front, else about the region the focus is
  in (the nearest `data-help` ancestor in `ui.html`). A surface the map marks `none` answers nothing and the browser's
  own help does not open there either.
- **Rule 2 - the button.** The `app.help` glyph (vendored in `assets/glyphs/`), named and titled `Help (F1)` from the
  vocabulary's name in all 13 languages (`titleHelp` in `i18n.js`), is the trailing control of the header row (ticket 119
  moved the theme and language selects off the header, onto the first page, and added the Pages button that appears
  only in a narrow window); the same button sits in the corner of the dialogs that have help.
  `cmd/doc-html-ui/help_test.go` holds the header's control set.
- **Rule 4 - the map.** `cmd/doc-html-ui/help/help-map.json`: the converter window and the settings pages (pages), the
  cost, secret-file and failure dialogs (pages), and `none` with a reason for confirmations, notices and the two OS
  pickers. The map is named in [`AGENTS.md`](../../AGENTS.md) and ships inside the exe.
- **Rules 5-11 - the answer.** One page per surface in the form of the reference template, generated by
  `tools/helpgen` from a copy deck, the GUI dictionary and the real build; no layer form is built (decision 1 of
  ticket 118). A page opens in the help window of the session (`window.open(url, 'dht-help')`), so a modal question
  stays open and answerable.
- **Rule 12 - offline.** The pages are embedded (`go:embed all:help`) and served from the local server under `/help/`
  with a content policy that admits nothing from another origin; the server stays alive for a grace period after the
  last help request so a help window left open keeps its links.
- **Rule 13 - language.** Authored in `en`, `ru`, `uk`; the other ten GUI languages fall back to the English pages by
  the resolver and are the set baseline `configs/help-baseline.txt` (the tier decision of ticket 118: they fan out at
  the release boundary, canon invariant 17). Names and one-line summaries come from `i18n.js`.
- **Rule 14 - screenshots.** Light and dark, per locale, from a scratch profile with demo documents; pin positions
  from the DOM's own bounding boxes; the generator refuses a capture that shows the machine's path or user name.
- **Rule 15 - address.** Help ids (`converter`, `settings`, `cost-question`, `secret-file-password`, `run-failed`,
  `index`) are permanent once a build ships; the site copy lives at `help/<locale>/<id>.html`.
- **Rules 17-19 - resolver, ship together, gate.** `help.js` is the one resolver; `scripts/help-check.ps1`
  (`internal/helpcheck`, also `tests/help_test.go`) counts the surfaces of `ui.html` against the map, the pages against
  the locale set, the links, rule 12, the house text style, the two copies of the set and, as an advisory, the
  freshness of the set against the digests of its inputs.

**Conformance.** Rung 1 (static) holds in the gate. Rung 2 (freshness): `node tools/helpgen/generate.mjs --check` by
hand, and the digest advisory in the gate. Rung 3 (walk): the automated matrix `tools/helpgen/walk.mjs`, recorded in
`DEV/plan/118_2026-10-16_in-app-help-f1-and-help-button/WALK.md`; the physical pass (the operating system's F1, 150 and
200 percent scaling, high contrast, a screen reader) rides ticket 93's pending pass.
