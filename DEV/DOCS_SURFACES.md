# Documentation surfaces

The single list of user-facing text surfaces that move **together** when a feature ships.
Session logs show this set being re-discovered by hand every time ("обнови документацию") and
individual languages being asked for as separate follow-ups. Treat it as one manifest so no
surface is forgotten and **en/ru/uk is one atomic edit, not three requests**.

Driven by the `/docs-sync` skill. Keep this file honest: when a surface is added or renamed,
edit the table.

## Surfaces

| Surface | Files | Languages | Notes |
|---|---|---|---|
| Repo README | `README.md` | en | Top-of-repo user pitch + feature list. |
| Landing page | `index.html` | en/ru/uk in-page | GitHub Pages hero. A new feature **leads the hero**, not a collapsed section (see memory `feature-prominence-3-lang`). Language handled in-page - edit all three copies inside the one file. |
| Extension page | `extension.html` | en/ru/uk in-page | Browser-extension landing section. |
| App docs | `docs.html` · `docs.ru.html` · `docs.uk.html` | en / ru / uk (separate files) | **The 3-language trio.** Change all three in lockstep; content must be mirrored, only the prose is translated. |
| Extension README | `extension/README.md` | en | Dev/user readme for the extension edition. |
| Store listing | `extension/store/LISTING.md` | en (+ ru/uk blocks) | Chrome Web Store / Edge listing copy + "What's new". Regenerated per release. |
| Store privacy | `extension/store/PRIVACY.md` | en | Only when data handling changes. |
| Extension i18n | `extension/_locales/en/messages.json` · `.../ru/...` · `.../uk/...` | en / ru / uk | **The 3-language trio for the extension UI.** Keys must match across all three; add a key to all three or none. |
| Dev changelog | `DEV/CHANGELOG.md` | en | Not "docs" per se, but ships with the change - use `/changelog`. |

## Invariants

- **3-language parity is mandatory** (docs/PARITY.md). `docs.*` and `messages.json` trios must carry the
  same information in en/ru/uk; never leave a language behind for "later".
- A **new user-facing feature leads** the landing hero and is mirrored across every surface above, in all
  three languages, without being asked (memory `feature-prominence-3-lang`).
- Typography everywhere: short hyphens, Russian ё, ".." not "..." (CLAUDE.md).
- Screenshots (`extension/store/screenshots/*`, `tools/store/*.png`) are regenerated by their own scripts
  (`tools/store/make-screenshot.ps1`), not hand-edited.
