split - plus the two commands that keep the local media honest: `ocrlab verify` and `ocrlab fetch`.

> Create package `corpus` with a `Manifest` (`SchemaVersion int`, `Scenes []Scene`) and a `Scene`

### Step 01.2 - Encode the licence allowlist as a gate

**Files:** `tools/ocrlab/corpus/corpus.go`
**Depends on:** Step 01.1

**Prompt for developer:**
> Add a closed `Licence` string type with the only accepted values: `PD`, `PDM`, `CC0`, `CC-BY-3.0`,
> `CC-BY-4.0`, `OWN` (the author's own material) and `SYNTHETIC` (generated by the lab). Add
> `func (l Licence) NeedsAttribution() bool` - true for the `CC-BY-*` values only. Add
> `func (l Licence) Valid() bool`. Anything else - non-commercial, no-derivatives, unclear, unstated -
> is invalid by construction, so a bad entry cannot be spelled.

**Verification:**
- `LicenceCC0` (or the equivalent constant set) declares all seven values exactly once.
- `func (l Licence) NeedsAttribution() bool` matches exactly once.

### Step 01.3 - Implement the §4.1 shape validator

**Files:** `tools/ocrlab/corpus/verify.go`
**Depends on:** Step 01.2

**Prompt for developer:**
> Add `func Validate(m *Manifest, root string) []Problem`, where `Problem` has `SceneID`, `Rule` and
> `Detail`. It reports, never panics, and never fixes: duplicate IDs; an invalid or missing licence; a
> `CC-BY-*` scene with empty `Attribution`; an empty `LicenceVerifiedBy` (the human gate - a manifest
> entry is invalid until a person read the licence page); a missing `SourceURL` on a non-`SYNTHETIC`
> scene; a `DerivedFrom` pointing at an unknown ID; a media file present on disk whose SHA-256 differs
> from `SHA256`; a media file absent from disk. Then the corpus-shape rules: the per-category minimums
> from strategic §4.1, a total of at least 200 scenes, a holdout of at least 30%, and no single
> category exceeding 35% of the holdout. Return the problems ordered by rule then scene so output is
> diffable.

**Verification:**
- `func Validate(m *Manifest, root string) []Problem` matches exactly once.
- The category-minimum table declares all seven §4.1 categories with their minimums.
- `35` and `30` appear as named constants, not inline literals.

**Status:** `[x]` done

### Step 01.4 - Implement the idempotent fetcher

**Files:** `tools/ocrlab/corpus/fetch.go`
**Depends on:** Step 01.3

**Prompt for developer:**
> Add `func Fetch(m *Manifest, root string, ids []string, w io.Writer) error`. For each selected scene:
> skip when the file exists and its hash matches; refuse when `LicenceVerifiedBy` is empty; refuse a
> `SYNTHETIC` or `OWN` scene (nothing to download - those are produced locally); otherwise GET
> `SourceURL` with a plain `net/http` client, no credentials and no cookie jar, write to a temp file in
> the same directory, hash it, and rename into place only on a hash match. A mismatch leaves the temp
> file for inspection and is reported as an error. Print one line per scene: `ok`, `skip (present)`,
> `FAIL <reason>`.

**Verification:**
- `func Fetch(m *Manifest, root string, ids []string, w io.Writer) error` matches exactly once.
- `os.Rename` is called only after a hash comparison in the same function.
- No `http.Client` field sets a `Jar`.

**Status:** `[x]` done

## Handoff notes

`corpus.Scene.ID` is the join key for everything downstream: annotations (Phase 02), evidence (Phase 04
and 05) and the report (Phase 06) all address a scene by that string. `Validate` reports and never
repairs, so a later phase can call it as a gate without side effects.
