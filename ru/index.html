Читайте, ищите и переводите встроенным движком браузера - бесплатно, приватно, без ключей.

Для тех, кто читает книги и документы на чужом языке: EPUB, PDF, MOBI, FB2, RTF, TXT, Markdown, HTML, комиксы и изображения превращаются в локальный HTML с оглавлением и навигацией. Для изображений доступен OCR.

EPUB / PDF / FB2 / CBZ / ..→local index.html→Chrome / Edge→чтение и перевод

Установка

Настольное приложение (окно + командная строка) и расширение для браузера устанавливаются независимо. Все варианты бесплатны.

Microsoft Store GitHub Releases v26.1021.0300 Что нового Установщик setup.exe Chrome Web Store v26.1021.41 Edge Add-ons v26.1021.41
  1. Установите приложение из Microsoft Store, через winget или установщиком; либо скачайте portable-архив из GitHub Releases.
  2. Откройте поддерживаемый файл в окне приложения или командой ниже.
  3. Приложение создаст HTML и откроет его в браузере; перевод - через меню браузера «Перевести».
winget install SerZhyAle.DocHtmlTranslate
doc-html-translate.exe "book.epub"
Важно

По умолчанию приложение конвертирует и открывает файл без платного перевода. Google Cloud и Ollama - отдельные режимы.

Windows protected your PC?

Установщик и portable-программы не подписаны сертификатом разработчика, поэтому Windows SmartScreen может остановить первый запуск. Нажмите «Подробнее», затем «Выполнить в любом случае». Версия из Microsoft Store подписана Microsoft и этого окна не показывает. Почему так и чего приложение никогда не делает.

# Что нового

Новое: картинки JPEG XL - откройте .jxl-файл или книгу либо комикс с картинками JPEG XL: они декодируются локально встроенным декодером и затем показываются, распознаются и переводятся, как любое другое изображение. Ничего дополнительно ставить не нужно.

Новое: окно с меню из семи страниц - окно приложения перестроено: сбоку меню из семи страниц, а на странице «Интерфейс» - размер интерфейса, размер текста и режим мыши или касания. F1 или кнопка «?» открывает справку по той части окна, где вы находитесь (на английском, русском и украинском).

# Для чего нужен

Четыре основных сценария без привязки к конкретной читалке или онлайн-сервису.

READ

Открыть книгу или документ

Получить локальную страницу с оглавлением, навигацией, темами и сохранением позиции.

TRANSLATE

Перевести в браузере

Открыть HTML в Chrome или Edge и использовать штатный перевод всей страницы.

OCR

Распознать текст на изображении

Добавить переводимые текстовые слои к скану, изображению или странице комикса. Плашки закрывают буквы, которые заменяют, а кнопка в шапке прячет весь слой, чтобы посмотреть рисунок под ним.

LOCAL

Сохранить результат локально

Обычная папка с HTML и ресурсами; её можно переносить и открывать повторно.
